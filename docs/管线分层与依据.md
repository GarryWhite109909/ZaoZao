# 两阶段管线分层与依据表（P6）

> 目的：把确定性管线的每一层标注为【通用安全知识】或【经验阈值（由 87 段打磨）】，
> 使未来换分布时能快速判断哪些层可能不迁移。维护责任：每次动管线必须同步本表。

## 已知迁移风险 Top3

1. ±行邻域类阈值（证据门1/形态门②）：换语言/换文件形态先复测；
2. 共形校准：换任何测试分布前必须重校准或禁用；
3. `_INPUT_ENTRY`/`_HAS_FUNCTION_DEF_RE` 正则枚举：新框架入口形态（如 Next.js handler 导出）可能不在枚举内。
