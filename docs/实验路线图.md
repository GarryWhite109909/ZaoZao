## P2 alpha06 评估（按测试集建设方案 §五 协议）

- **前置**：P1 Exit
- **动作**：
  1. L0 87 段回归（triage_train_aligned, N=3, --no-signal-feedback）；
  2. L1 rolling_dev 首测（vuln 50 + real-safe 50——safe 侧若未拉取此时补齐）；
  3. CVE-fix 20 对照基线（fixed5: recall 0.882）；
  4. 分开报告端到端指标与 stage1 工具覆盖率；
  5. 与 fixed5 逐样本 diff，失败案例进分诊表。
- **红线**：87 段 recall 不得回退；cve_fix20 recall ≥0.882；
  若 FPR@real-safe 高于合成集 FPR 一倍以上 → FP 弱点确认，记入 P3 重点
- **Exit**：评估报告 + 失败分诊表落盘；**此时方可对外引用 alpha06 数字**

## L 层（测试集建设，穿插执行）

- L1 safe 侧：机械操作，可在 P2 前任意时点做（不依赖训练集冻结）；
- L2 锚定探针集：**必须在 P0.3 冻结日之后开始写**（污染门 0.3 对最终训练集），
  第一批框架习语 15 + 硬安全 15，第二批其余；详见测试集建设方案 §三。

## P3 失败采集（on-policy rejected）

- **前置**：P2 Exit（需要 alpha06 权重 + 失败分诊表定重点）
- **动作**：alpha06 在 train_pool 种子 + 内部材料上全量推理（transformers 后端，
  与部署形态一致）；采集三类真实失败输出原文：FP 判定 / strict CWE 错标 /
  格式失效；每条失败配 ground-truth（语料标签 + patch）
- **Exit**：`dpo_failures_alpha06.jsonl` ≥300 条失败，覆盖三类

## P4 DPO 配对 + 云端训练

- **前置**：P3 Exit
- **动作**：
  1. rejected = 真实失败输出原文（**禁止**标签翻转式合成——旧 104 对已归档弃用）；
  2. chosen = ox-alpha 重写（advisory 标签 + patch 事实校准，同 SFT 蒸馏防误标设计）；
     FP 对优先（直接打最小化误报）；
  3. 目标 300~800 对；云端 DPO：r8、lr≤1e-5、beta 0.1、**1 epoch 封顶**；
  4. 训练前后各跑一次 L0 回归。
- **红线**：recall 回退即停（v6 教训）；DPO 版本号独立（如 alpha06-dpo1），不覆盖 SFT 权重
- **Exit**：L1/L2 复测报告，FPR 相对 alpha06 下降且 recall 不回退

## P5 GRPO（可选，P4 收益见顶再启动）

- 规则奖励四件套：格式可解析 / 标签正确 / strict CWE 命中 / 行号有效——无需奖励模型；
- TRL + vLLM rollout 云端工程量大，仅在 P4 后仍有明确收益空间时立项；
- 立项前先写一页可行性备忘（算力预算、expected reward 曲线）。

## 飞轮循环（P2 起每轮持续）

冻结集评估 → 失败分诊 → 三路分流（靶向数据补充 / prefilter 新规则 / learn_pool 沉淀）
→ 下轮重训。每轮只允许动一处大变量（数据 OR 训练法），否则归因失效。
