## 二、快速上手（三步）

### 第 1 步：构建 PDF

```bash
cd 01_说明书稿
bash build_pdf.sh
# 产物：build/说明书正文.pdf
```

首次需安装工具链：

```bash
sudo apt install pandoc texlive-xetex texlive-lang-chinese fonts-noto-cjk poppler-utils qpdf
```

### 第 2 步：套封面

1. 用 LibreOffice 打开官方封面模板 docx，按 `01_制作说明_封面与前置页.md` §1 填字段；
2. **删除模板页脚提示行**；
3. 另存为 `封面.pdf`；
4. 合并：`qpdf --empty --pages 封面.pdf build/说明书正文.pdf -- 最终.pdf`

### 第 3 步：终检

```bash
bash check_anonymity.sh 最终.pdf
```

必做三项终检：
1. **匿名**：命令零命中（学校 / 姓名 / 用户名 / 模型全名）；
2. **目录页码正确**：打开 PDF 目录逐条点跳转；
3. **图片清晰度**：打印预览确认图表文字可读。
