## 三、写作模板（每篇统一骨架）

每篇 Markdown 文件遵循下面骨架，保证风格统一、便于评委按官方清单勾对：

```markdown
# 第X篇  <官方文档名>

> **本篇对应官方材料**：<功能需求说明书 / 概要设计说明书 / …>

## X.1  <节标题>

正文……

### X.1.1  <小节>

正文……

> 表 X-1  <表标题>
（表格）

> 图 X-1  <图标题>
（图片）

### X.1.2  <小结>

- 要点一
- 要点二
```

**编排约定**：

1. **图表编号**：`表 X-N` / `图 X-N`，X 为篇号，N 为篇内序号；正文引用写「见表 3-2」。
2. **图片语法**：`![图 3-1 两阶段扫描架构](assets/two_stage_architecture.png)`——路径统一走 `assets/`（构建时由脚本从 `04_图片资产/架构与数据图/` 拷贝）。
3. **代码块**：pandoc 转 PDF 时用 `listings`/`fvextra` 高亮；超过 30 行的贴代码片段放附录。
4. **表格**：窄表（≤4 列）用 pipe 表；宽表建议改为「字段说明」列表或旋转处理。
5. **术语**：首次出现写全称 + 缩略语，如「通用弱点枚举（Common Weakness Enumeration, CWE）」；其后用缩略语。
6. **数字口径**：一切指标数字必须能在 `素材库_论文写作素材收集.md`（2026-09-08 统一口径）中找到出处；**禁止自行计算或估算**。

## 四、构建流水线

### 4.1 依赖

```bash
# 必需
pandoc          >= 3.0        # 文档转换
xelatex         (texlive-xetex)   # 中文 PDF 引擎
fonts-noto-cjk  # 中文字体

# 可选（封面合并 / 检查）
pdftk 或 qpdf   # PDF 合并
poppler-utils   # pdftotext（匿名终检）
```

Ubuntu/Debian 安装：

```bash
sudo apt install pandoc texlive-xetex texlive-lang-chinese texlive-fonts-recommended \
                 fonts-noto-cjk poppler-utils qpdf
```

### 4.2 构建脚本（已随本手册提供）

见 `build_pdf.sh`（Linux/macOS）——它会：

1. 把 `04_图片资产/架构与数据图/*.png` 与 `04_图片资产/界面截图/*.png` 复制到 `assets/`（只拷正文引用的）；
2. 按 `01`→`10` 的顺序合并全部篇文件为 `build/说明书合并.md`；
3. 调 pandoc 生成 `build/说明书正文.pdf`（带目录、自动章节编号、中文字体）；
4. 提示下一步（封面合成与匿名检查）。

### 4.3 pandoc 关键参数说明

| 参数 | 作用 | 为何需要 |
|---|---|---|
| `--pdf-engine=xelatex` | 中文 PDF 引擎 | pdflatex 不支持 CJK |
| `-V CJKmainfont="Noto Serif CJK SC"` | 中文字体 | 避免方框/乱码 |
| `-V mainfont="Noto Serif"` | 西文字体 | 与中文协调 |
| `--toc --toc-depth=3` | 生成目录 | **官方硬要求** |
| `--number-sections` | 自动章节编号 | 保证图表引用可定位 |
| `-V geometry:a4paper,margin=2.5cm` | 页边距 | 双面打印友好 |
| `-V linestretch=1.3` | 行距 | 中文可读性 |
| `--listings` | 代码块排版 | 保留等宽对齐 |
| `--highlight-style=tango` | 代码高亮 | 阅读舒适 |
| `-V documentclass=report` | 文档类 | 支持 `\part` 篇章级结构 |
| `-N` | 编号 | 与 `--number-sections` 同义 |

### 4.4 封面合成

```bash
# 1. 填封面：用 LibreOffice 打开官方 docx 填字段（见 01_封面与前置页.md §1）
libreoffice --headless --convert-to pdf \
  "docs/省赛报名/附件/2026年竞赛公告附件/2026第22届...封面模板.docx"
# 2. 删除页脚提示行（用 PDF 编辑器或先改 docx 再转）
# 3. 合并：封面 + 正文
qpdf --empty --pages 封面.pdf 说明书正文.pdf -- 最终.pdf
```

> 若封面含身份信息与匿名条款冲突（见 01 §1.3），先完成合并，待组委会答复后再决定是否替换封面版本——正文不受影响。

## 九、常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 中文显示为方框 | 未指定 CJK 字体 | 加 `-V CJKmainfont="Noto Serif CJK SC"` |
| pandoc 报 `xelatex not found` | 缺 texlive-xetex | `sudo apt install texlive-xetex` |
| 图片在 PDF 中丢失 | md 里的路径在合并后失效 | 用 `build_pdf.sh`（自动拷到 `assets/` 并用相对路径） |
| 目录没有页码 | `--toc` 与模板冲突 | 确保 `documentclass=report` 且未覆盖 `toc` 模板 |
| 表格超宽 | pipe 表列数过多 | 拆表或改列表；必要时 `--columns` 调整 |
| 代码块换行错乱 | 未启用 listings | 加 `--listings` |
| 封面页脚提示行残留 | docx 转 PDF 时未删 | 先在 docx 中删除该行再转换 |
