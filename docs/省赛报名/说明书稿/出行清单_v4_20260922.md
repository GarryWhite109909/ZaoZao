### 4.1 图↔表完全重复（9 处，主要删表）

问题根源是**同一份数据在「图」和「表」里各呈现一遍**，评委翻页时会看到内容重复。

- **D1 删表**：第三篇 §3.5.3 的「6 后端 × 5 平台」矩阵表（24 格）与图 3-2 逐格同源，连 ●/◐/—/N/A 图例都一样 → 删表，**图 3-2 为唯一完整口径**。§8.5.1 的选型表因已标注「以第三篇为唯一事实来源」而保留。
- **D6 删表**：第四篇 §4.3 的「层级/名称/类型」4 行表与图 4-2 图内 ①②③④ 一一对应 → 删表，改为带小节号的分条列表（顺带成了导航）。
- **D2/D3 图注瘦身**：图 3-3（fixed 收敛）、图 3-6（量化缺口）的图注删掉了与图内数据标签完全重复的数值。
- **D4 补分工说明**：图 3-4（SFT 演进）与表 3-3 数据同源，补图注说明「表 3-3 = 四关键版本选点对比，图 3-4 = 完整九版轨迹（含 v4/v6/v8 三个失败版本）」。
- **D5/D7/D8 图注改述**：图 4-1（自研工具链）不再列举工具清单、图 4-3（回填门控）不再复述 A-E 与三条去向、图 3-1（两阶段架构）与上方 5 条 bullet 改为「图看数据流 / bullet 看文字口径」分工。

## 七、如果 typst 通道跑不起来

`build_pdf.sh` 是另一条通道（pandoc + xelatex），但它有已知缺陷——需要 `fonts-noto-cjk`，且**产不出 **typst 那套表格全框线 / 图题绑定效果**，v3 的版式是 typst 链的成果。所以：

1. 优先用 §二 的 typst 链；
2. 若 Windows 上 typst 或 pandoc 丢了（重装过系统等），按 `修订记录_代码对齐_20260921.md` §五之三 的说明重装：pandoc 走 winget，typst 从 GitHub release 下载 Windows msvc 版；
3. 极端情况才退回 `build_pdf.sh`，但需接受版式退化，并额外装 `fonts-noto-cjk`。
