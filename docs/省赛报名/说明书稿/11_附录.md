## 附录 B  CLI 命令速查

| 命令 | 功能 | 示例 |
|---|---|---|
| `health` | 健康检查（服务 + 模型可用性） | `python -m app.launcher.vuln_scanner_cli health` |
| `scan <file>` | 扫描单个文件 | `python -m app.launcher.vuln_scanner_cli scan app/main.py` |
| `batch <dir>` | 批量扫描目录下所有代码文件 | `python -m app.launcher.vuln_scanner_cli batch ./src --output report.md` |
| `url <url>` | 扫描 URL 抓取的脚本 | `python -m app.launcher.vuln_scanner_cli url https://example.com` |
| `github <repo>` | 扫描 GitHub 仓库（浅克隆） | `python -m app.launcher.vuln_scanner_cli github <仓库地址>` |

**通用参数**（所有子命令可用）：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--model` | 发布模型 | 切换模型 |
| `--ollama-url` | `http://localhost:11434` | Ollama 服务地址 |
| `--rag` | 关闭 | 启用知识库增强（较慢但更准） |
| `--format` | `text` | 输出格式：`text`（终端着色）或 `json`（结构化） |

**子命令专属参数**：

| 子命令 | 参数 | 默认值 | 说明 |
|---|---|---|---|
| `scan` | `--language` | 自动识别 | 覆盖语言检测（如 `python` / `javascript`） |
| `scan` / `batch` / `url` / `github` | `--output` | 无 | 报告输出路径（`.md` 或 `.json`） |
| `batch` | `--limit` | `0`（不限） | 最多扫描文件数 |
| `batch` | `--no-recursive` | 关闭 | 不递归子目录 |
| `github` | `--max-files` | `50` | 最多扫描文件数 |
| `scan` / `batch` | `--verbose` | 关闭 | 显示详细分析 |

**退出码契约**：健康检查返回 0/1；扫描有错误返回 1；用户中断（Ctrl+C）返回 130；其他异常返回 1。

**支持的文件类型**：`.py` `.js` `.ts` `.jsx` `.tsx` `.java` `.php` `.go` `.html` `.htm` `.vue` `.svelte`

## 附录 C  输入限制与支持范围

| 项目 | 限制 |
|---|---|

## 附录 D  评估口径说明


> 本篇口径为项目统一评估口径（2026-09-08），全部数字可由随附评估脚本复现。

### D.1  指标定义

| 指标 | 定义 |
|---|---|
| `acc` | `(TP + TN) / (TP + TN + FP + FN)`（仅在已裁决样本上计算） |
| `recall` | 漏洞样本被正确判出的比例（实例级） |
| `FPR` | 安全样本被误判为漏洞的比例 |
| `strict` | 判真且 CWE 归因正确（经归一化 + 父子族匹配） |
| `micro` / `macro` | 实例级 recall 的两种平均方式 |
| `加权` | 风险加权分（冻结权重表） |
| `未决率` | 系统不做自动结论、转人工复核的样本占比（与 acc 成对引用） |
| `parse_fail` | 模型输出无法解析的比例（计入漏报，不剔除出分母） |

### D.2  口径须知

1. **一套分数规则走全程**——所有表格使用同一套定义，数字可由评估脚本复现；
2. **两阶段系统**——未决率与 acc 成对引用；“干净评估”（关闭信号回填）与“完整信任层”（开启回填）引用时须注明组态；
3. **推理管道**——高精度形态（NF4 + FP16 LoRA）与发布形态（Q4_K_M 合并量化）指标不同，引用须注明管道；
4. **全正样本集**——只有 recall / acc 有意义，FPR 无定义（记「—」）。

### D.3  测试面构成

| 测试面 | 规模 | 构成 | 典型性 |
|---|---|---|---|
| 合成集 | 87 段 | 合成教学样本 | 72% |
| 真实 CVE 片段 | 20 段 | 真实 CVE 最小化片段 | 60% |
| 真实完整文件 | 50 段 | 真实完整文件（哈希冻结） | 6% |


### D.4  术语口径提醒

- 「召回率」统一写「recall」，避免中英混用；
- 「CWE」编号写法统一为 `CWE-数字`（带连字符）；
- 日期统一 ISO 格式；
- 未实测的估计值不得写入（如“多少比例的文件不进 LLM 裁决”一类推断）。
