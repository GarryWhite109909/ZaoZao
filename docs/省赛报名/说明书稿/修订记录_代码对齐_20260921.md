## 三、语义级修正（本批修复带来的新语义）

### 3.1 判定语义：三态 → **四态**（第二篇 2.1 / 2.3.1、第六篇 6.4.2）

新增第四态 **「未复核」（`not_covered`）**：工具零召回且本轮注意力预算未覆盖该文件——**模型从未被调用**。该状态与判定正交，通过 `review_coverage` 字段表达（`llm_checked` / `not_covered` / `unknown`）。

- 语义要点：「未复核 ≠ 已确认安全」。保留该状态的目的正是**不让"没看过"在界面上被渲染成"安全"**。
- 计分口径：「需人工复核」与「未复核」两类样本**均单列、均不参与扣分**。
- 第二篇 2.8.5 已补一条能力边界说明（未复核会按注意力预算出现，可切换全量复核组态）。

### 3.2 无候选复核组态：**生产默认统一为 `targeted`**（第三篇 3.1 / 3.3.4、第四篇 4.4.1）

原稿写「单文件 / GitHub 走 `full_recheck`，批量 / URL 走 `targeted`」——**修复后不再成立**：

- `_two_stage_scan()` 的参数默认值即 `BATCH_NO_CANDIDATE_MODE`（默认 `targeted`），三个批量入口与交互入口**共用同一组态常量**；
- `full_recheck` 仅用于 vLLM 端点与显式指定的演示 / 消融；`sampled` 为类默认与评估组态；
- 这样设计是为消除「行为随调用顺序漂移」（早期请求级参数覆盖共享配置后不回滚）。
- 第四篇 4.4.1 的场景对照表与口径提醒同步重写；图 3-1 图注同步。

### 3.3 工具-模型闭环的三处结构性修正（第四篇 4.3.4、图 4-2 / 4-3、第五篇 5.2.2）

| 项 | 原稿 | 改为 | 依据 |

| 门控数量 | 四重 | **五重**：新增「门控 0 · 与模型无关的证据门（前置否决）」——结论为需复核 / 被证据门拦截 / 反事实存疑一律拒收 | 实测：高精度后端上模型误报形态恰是"全票确认"；只用投票一致性做门槛，与已知失效模式正交 |

### 3.4 共形预测（Layer 1）的诚实降级（第四篇 4.3.2、第五篇 5.2.3）

原稿称「默认 alpha=0.1，保证覆盖率 90%」。实际情况：

- 项目自查发现生产端自动加载的校准文件是在**同一测试集**上拟合的（in-sample），交换性前提被破坏，"覆盖率保证"不成立；
- **处置**：该文件移出自动加载路径（存档保留、文件名带 `in_sample_leaked` 标识），生产端进入**未校准状态**——Layer 1 不参与判定，全部交后续门控与投票逻辑；加载失败时安全降级而非中断扫描；
- 正文改为如实声明当前状态，并把 Layer 1 的定位表述为**"与判定阈值解耦的统计门控接口"**（获得独立同分布校准集后可启用），同时说明 N=3 时自一致率只有 4 个取值、分辨率不足以支撑细粒度分档。

> 这是本轮最重要的诚实性修正：**不宣称一个不成立的统计保证**。

## 五之三、PDF 已在本机生成（typst 通道，2026-09-21 晚）

本机无 xelatex / qpdf，已改走 **pandoc 3.11 + typst 0.15.1** 通道在本机直接出稿（产物 `build/说明书正文.pdf`，102 页 / 6.97 MB / 28 图 / 目录 5 页带页码 / PDF 书签 215 条 / 匿名与版本红线零命中 / 元数据仅 `creator=Typst`）。`build_pdf.sh` 的 xelatex 通道仍保留，两条通道产物可互相校对。

**typst 通道的四个坑（换机器复现必读）**：

1. pandoc 直通 `--pdf-engine=typst` 会把图片复制进临时目录并写死 `C:/` 绝对路径，typst 报 "path contains invalid component C:" → 改两步走：`pandoc -t typst -s` 产出 `.typ` 源，再 `typst compile`；
2. `.typ` 内图片是 `assets/...` 相对路径，相对 `.typ` 所在目录解析 → 需前缀 `../`（共 28 处），并给 typst 加 `--root .`（否则沙箱拒读 `../`）；
3. `lang=zh-CN` 会被 typst 拒绝（要求 ISO 639-1 两字码）→ 不传 lang 变量；
4. pandoc `--toc` 在 typst 模板里输出 `#outline(title: auto)`，英文语境渲染为 "Contents" → 后处理把第一处 `title: auto,` 替换为 `title: [目录],`；篇间分页需在 10 个篇级 H1 前手动插 `#pagebreak()`（合并稿里的 `\newpage` 是 raw LaTeX，typst writer 会丢弃）。

**本机工具落点**：pandoc `C:/Users/zane/AppData/Local/Pandoc/pandoc.exe`（winget）；typst `C:/Users/zane/.workbuddy/binaries/tools/typst-x86_64-pc-windows-msvc/typst.exe`（GitHub release 经 7897 代理下载）。字体用系统 SimSun / Consolas（Noto Serif CJK 未安装；如需与 Linux 端 Noto 版式完全一致，在装齐 fonts-noto-cjk 的机器上跑 `build_pdf.sh` 重出即可，正文内容不受影响）。

## 五之五、typst 通道排版打磨（2026-09-21 晚，用户反馈「表格无线条 / 莫名空白 / 文字重叠」后执行）

**根因**（均在 pandoc 默认 typst 模板与输出形态，非内容问题）：

| # | 用户可见症状 | 根因 |
|---|---|---|
| 1 | 95 张表几乎无线条 | 模板默认 `#set table(stroke: none)`，仅表头下一条 `table.hline()` |
| 2 | 大面积空白（最多 81% 页高） | pandoc 把 123 个表/图全包进**不可跨页**的 `#figure`，大表/整页图放不下就整体跳页 |
| 3 | 文字重叠（术语表 p9 底部） | 超页高的表在不可跨页 figure 里**溢出叠印** |
| 4 | 「Figure 8: 图 3-8 …」英文双标题 | pandoc 对带 alt 的图片自动生成英文编号 caption，与正文手写「图 X-N」图注重复 |

**修复**：新增 `polish_typ_for_pdf.py`（幂等，处理 pandoc 产物 `.typ`，位于本目录），五类变换 + 两轮实测修正：

- A. 表格全框线 `0.5pt + luma(60)`、表头加粗 + 浅灰底 `luma(242)`（typst 跨页自动重复表头）；
- B. `#show figure: set block(breakable: true)` + `#set block(breakable: true)`——表/图可跨页，消除跳页空白与溢出叠印；
- B2. `#show table.cell: it => block(breakable: false, it)`——**行原子化**，杜绝「半行残片 + 两列空白」式跨页拆行（首轮验收唯一 fail 项，p9 术语表）；
- C. 删除 28 个图片 figure 的英文 caption（保留 alt），英文「Figure N:」绝迹；C2. 图片按**实际宽高比单边约束**：横图限宽 82% 版心、竖图限高 66% 页高（从 assets/ 读像素尺寸判断）。**切忌宽高同时约束**——contain 会把图缩得很小、盒子却照预留，页面中央一片留白（p67 图 6-1 教训）；
- D. 表格去 `align(center)[…]` 包裹（该包裹把单元格 auto 对齐传染成居中）、等宽百分比列改 auto 整数列（按内容自适应）、清理 `align: (auto,…)` 冗余行；
