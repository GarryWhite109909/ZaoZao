## 6.1  设计系统

### 6.1.1  设计哲学

> **"专业的安全工具应该是隐形的，数据 > 装饰"**

不以动画堆砌博眼球，而是让安全工具"不打扰用户"，把数据清晰度放在首位。

### 6.1.2  双层令牌体系

| 层 | 文件 | 内容 |
|---|---|---|
| 基础令牌 | `design-tokens.css` | 全站 CSS 变量：颜色 / 圆角 / 间距 / 阴影 / 字体 |
| 语义令牌 | `@theme inline` 映射 | 映射到框架语义 token，5 个页面共用 |
| 动效系统 | `lively.css` | 统一动效曲线、玻璃卡片、导航栏与健康指示灯 |

**特性**：

- 深浅双色系完整覆盖；
- `<head>` 内联同步脚本在 CSS 加载前读取主题设置并应用主题类，**规避闪烁**（FOUC）；
- 支持 `prefers-reduced-motion`（尊重系统的"减少动效"设置）。

### 6.1.3  零依赖手写 SVG 图表

全部图表手写 SVG，**无第三方图表库**：

| 图表 | 实现 |
|---|---|
| 折线趋势图 | `<polyline>` + 渐变 |
| 环形分布 | `<circle>` + `stroke-dasharray` |
| 柱状图 | `<rect>` 系列 |
| 评分圆环 | 用三角函数逐帧重算弧路径的 `d` 属性，从根上规避特定浏览器"圆头线帽 + dasharray 动画"的渲染位移缺陷 |

**收益**：零外部依赖、离线可用、体积可控、渲染一致性可保证。

### 6.1.4  视觉规范摘要

| 元素 | 规范 |
|---|---|
| 主色 | 沿用安全工具惯用的冷色调，配合语义色（危险/警告/安全） |
| 风险等级色 | Critical / High / Medium / Low 四级固定语义色 |
| 卡片 | 玻璃拟态（半透明 + 模糊），深浅主题各自适配 |
| 健康指示灯 | 引擎状态用颜色 + 文案双通道表达（不只依赖颜色，兼顾可访问性） |
| 圆角 / 间距 | 由令牌统一，避免页面间漂移 |

## 6.4  关键交互

### 6.4.1  主题切换

采用 View Transition API 实现交叉淡化，带 `_inTransition` 防重入保护，支持跨标签页同步；不支持该 API 的浏览器直接切换（优雅降级）。

### 6.4.2  扫描结果呈现流程

```
用户提交代码
   │
   ▼
[进度指示] ── 批量扫描时逐行显示 NDJSON 进度
   │
   ▼
[结果区] 漏洞判定（三态色标签）
         ├─ CWE 类型 + 风险等级
         ├─ Source & Sink 行号（可点击定位）
         ├─ 漏洞说明
         ├─ 修复建议
         ├─ 信任层明细（裁决档位 / 置信度 / 共形预测 / 反事实 / 证据门）
         └─ 模型原始输出（可折叠）
   │
   ▼
[安全评分] 评分圆环动画（arcPath 逐帧重算）
   │
   ▼
[导出] 「下载报告」→ Markdown
```

### 6.4.3  交互健壮性设计

| 场景 | 设计 |
|---|---|
| 深度健康检查耗时长（最坏 30s+） | sessionStorage 缓存 + `AbortController` 在页面切换时主动中止，避免占满同域 HTTP 并发连接 |
| 批量结果重复入账 | 双保险机制保证"一轮只入账一次" |
| 数据格式演进 | 旧数据自动迁移 |
| 长连接被代理掐断 | 模型下载流空闲时发心跳帧保活；响应头禁用中间层缓冲 |
| 评分语义 | 统一扣分制（Critical/High 每项 -8、Medium -4、Low -2、Info -0.5）；两阶段"需复核"样本单列、不计入安全与错误，保证评分语义与复核信号不混 |
| 深链接 | 演示样本库支持多类查询参数深链接，页面间互相跳转闭环 |

### 6.4.4  可访问性

- 风险等级与引擎状态用**颜色 + 文案**双通道表达，不单纯依赖颜色；
- 尊重系统 `prefers-reduced-motion`；
- 表单与按钮保持足够的点击区域与键盘可达性。

### 6.4.5  编辑器插件交互

| 插件 | 交互 |
|---|---|
| VS Code | 右键菜单 / 命令面板 / 编辑器标题栏图标三种入口；结果以 Webview 面板展示，含信任层明细表格；每个确认的漏洞按行号标红色波浪线；保存时自动扫描采用 `onDidSave`（而非保存前阻塞），避免等扫描完成才落盘 |
| IntelliJ | 编辑器内选中代码 → 右键菜单或快捷键；结果以气球通知弹出；后端地址支持在弹窗中修改 |
