   - 标题：`衡阳师范学院+应用开发类+X个作品`
   - 正文：各作品百度网盘链接+提取码
   - 附件：全部盖章报名表 PDF；同时把 PDF 压成 RAR/ZIP 上传报名系统。

## 五、可安装软件 ZIP 打包要点

- 源码：用 `git archive` 干净导出（排除 .git、__pycache__、实验大文件、模型权重）；
- 可运行件：VS Code 插件 `releases/vuln-scanner-1.3.0.vsix`；Web 端为后端 + static 静态页（无需 node 构建）；`app/launcher/start_windows.bat` 一键启动（bootstrap 自动装依赖）；
- IntelliJ 插件目前**无构建分发包**（只有源码），需 gradle 构建或在手册中说明；
- 模型分发：默认 Ollama 后端首次启动自动拉取发布模型（约 5GB Q4），**需确认该 Ollama 模型已公开发布**；网盘中不放 16GB 基座；
- 交付前务必在一台**没有开发环境的干净 Windows 电脑**上走一遍安装→启动→扫描全流程（形式审查与复赛可能现场试运行）。
