## 一、官方要求速查（以通知原文为准）

### 1.1 材料内容要求（通知 P10「（二）应用开发竞赛 · 3. 材料提交」）

> 每一件作品需通过网络提交以下材料电子版：**功能需求说明书、概要设计说明书、详细设计说明书、数据库设计说明书（如必要）、软件界面设计书、用户操作手册**、全部源程序代码及编译后的可执行文件、介绍整个作品的 PPT 等，**材料不齐全扣分**。

- 前六项整合为**一个 PDF**（网盘文件夹「系统设计说明书」，命名 `衡阳师范学院N号作品+信息安全类+系统设计说明书.pdf`）。
- 「数据库设计说明书」标注**（如必要）**：本系统无独立数据库（见 §3.5），按官方口径写「本地数据存储设计」一篇即可，**不算缺材料**。

### 1.2 ⚠️ 匿名红线（通知 P11「6.」，违者成绩无效）

> 所有参赛作品（**含说明书、操作手册等**）不能出现任何可能影响评审公正性的身份信息，包括但不限于**学校名称、校徽、指导教师信息、参赛者姓名**等，一经发现，一律视作参赛成绩无效。

由此产生的三条硬约束：

1. **正文全篇匿名**：不出现「衡阳师范学院」、校徽、队员/导师姓名、学院名。
2. **已发现的暴露点必须处理**：
   - `docs/用户手册.md` §2.2 与 README 快速开始中的 `github.com/GarryWhite109909/ZaoZao`——**GitHub 用户名疑似个人 ID**。改写为「源码随作品 ZIP 提交」或用匿名仓库地址；同理排查 ZIP 内 README。
   - 用户手册内链（`项目历程.md`、`README.md` 等 md 相对链接）转 PDF 前删除或改纯文字。
3. **封面冲突待确认**：官方封面模板本身含「作者 / 指导老师 / 单位」字段与承办方（吉首大学计算机科学与工程学院）抬头图片——模板是官方发的、报名清单已定「必须套用」，与匿名条款存在张力。**建议：正文严格匿名 + 封面按模板填写，并在组委会 QQ 群（850146901）确认一次封面处理方式**（这是唯一无法自行裁决的事项）。

### 1.3 封面模板的排版要求（模板页脚原文）

> 「注意：正文内容要求有**目录**，**双面打印**，封面封底用白色纸，**胶装，一式 2 份**（打印时请删除此页脚）」

- PDF 必须**有目录页**（正文第一篇前）；
- 封面用官方 docx 填好后转 PDF 置于首位，**删除模板页脚提示行**；
- 纸质胶装 2 份属于后续决赛/存档要求，电子提交阶段按 PDF 准备即可。
