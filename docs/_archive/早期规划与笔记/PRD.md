# VulnScanner — 前端功能需求文档

## 产品说明

AI 代码漏洞扫描平台。用户输入代码（粘贴/上传/URL/GitHub），由本地 AI 模型检测漏洞，输出风险等级、漏洞类型、CWE 编号和修复建议。面向开发者和安全分析师的日常工具。

---

## 全局

### 导航栏
- 产品标识（名称 + 图形）
- 4 个导航入口：仪表盘 / 扫描工作台 / CWE 样本库 / 安全态势，标记当前所在页
- 主题切换（深色/浅色）

### 页脚
- 产品说明文字
- 数据更新时间

### 数据通道
- localStorage 持久化扫描历史（`vuln_scan_history`），刷新不丢失
- 异步请求后端 `/api/stats`、`/api/health/live`、`/api/health` 补充数据
- 首屏先用 localStorage 秒级渲染，后端数据到达后覆盖

### 主题系统
- 深色为默认
- localStorage（`vuln-theme`）持久化
- 跨标签页同步（storage 事件）
- 防 FOUC（head 内联早期脚本）

## 页面 1：仪表盘

**目标**：总览安全状态。

### 页头
- 页面标题
- 后端连接状态（在线/离线 + 模型名）

### KPI 区（4 项指标）
1. 本月扫描次数 + 副信息
2. 高危漏洞数 + 副信息
3. 修复率（百分比）+ 趋势对比
4. 平均风险分（基于严重度权重均值）

每项含：标签、数值、副信息、图标。

### 风险分布 donut 图
- 4 段：高危 / 中危 / 低危 / 信息
- 中心显示总数
- 段可交互：hover/click 显示该段百分比，图例联动
- 图例：色块 + 标签 + 百分比

### 扫描趋势折线图（近 7 日）
- X 轴日期，Y 轴数值
- 渐变面积填充
- 数据点标记

### 最近动态列表
- 最近 8 条发现
- 每条：风险等级、文件名、漏洞类型、相对时间

### 快捷入口
- 粘贴代码分析 → 跳转扫描工作台
- 上传文件扫描 → 跳转扫描工作台
- GitHub 仓库安全态势 → 跳转安全态势

## 页面 2：扫描工作台

**目标**：输入代码 → 执行扫描 → 查看结果。

### 左侧输入面板

**5 个输入方式 Tab**（带滑动指示器）：
1. 粘贴代码 — 语言选择下拉 + 代码文本框
2. 上传文件 — 拖拽区 + 文件选择 + 已选文件列表
3. URL — 单行输入框
4. GitHub — 仓库地址 + 最大文件数
5. 快速演示 — 样本下拉 + 样本元信息（CWE/预期结果/说明）+ 加载按钮

**高级选项**（可折叠）：
- 多模型对比开关 → 开启后显示模型多选
- 启用外部工具开关 → 开启后显示工具信息

**引擎状态**：当前引擎名 + 连接状态

**扫描进度**（扫描时显示）：
- 状态文字 + 百分比 + 进度条
- 资源紧张时显示警告横幅

**操作**：开始分析按钮

### 右侧结果面板

**结果头部**：
- 结果计数
- 严重级别筛选（全部/严重/高危/中危/低危/信息）
- 下载报告按钮（导出 Markdown）

**结果卡片**（每条）：
- 文件名 + 风险等级
- 漏洞类型 + CWE 编号
- 漏洞代码片段
- AI 分析说明
- 修复建议 + 安全代码示例
- 可展开收起

**状态**：
- 空状态提示
- 扫描中加载状态

### 底部报告历史
- 历史记录列表
- 清空按钮
- 说明"本地持久化"

## 页面 3：CWE 样本库

**目标**：漏洞类型知识库。

### 页头
- 标题
- 统计：总数 + 显示数 + 检测摘要

### 搜索与筛选
- 搜索框（CWE ID / 名称 / 关键词）
- 严重级别筛选

### CWE 卡片网格
每张卡片：
- CWE 编号
- 严重等级
- 漏洞名称

### CWE 详情弹窗
- CWE 编号 + 严重等级 + 分类 + 关闭
- 漏洞名称
- 漏洞描述
- 检测要点
- 漏洞代码示例（含语言标签）

- 适用语言标签

## 页面 4：安全态势

**目标**：仓库级安全评估。

### 仓库输入
- 仓库地址输入框
- 分析按钮

### 元信息栏
- 仓库名称 · 分析时间 · 扫描文件数

### 综合风险评分
- 评分环（0-100）
- 中心：分数 + 等级标签
- 评分描述

### 漏洞统计（5 项）
- 总计 / 严重 / 高危 / 中危 / 低危 / 信息

### 图表区
1. 严重等级分布柱状图（5 根柱子，可 hover）
2. 近 7 天风险评分趋势折线图

### 优先修复清单（表格）
- 列：文件 / 漏洞类型 / 风险等级 / CWE / 建议
- 按风险等级排序
- 行可 hover

## 通用交互约定

- 风险等级归一化：critical/严重、high/高危、medium/中危、low/低危、info/信息
- 相对时间显示：秒前/分钟前/小时前/天前/日期
- 数字千分位格式化
- 响应式：1024px 以下网格降为单列
- 无障碍：focus-visible 焦点环、aria 标签、尊重 prefers-reduced-motion
- 图表全部原生 SVG 实现，无图表库
- 图标用 Lucide
