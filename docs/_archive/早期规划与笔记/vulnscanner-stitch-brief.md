# VulnScanner — AI 漏洞扫描平台前端功能规格

## 产品定位

这是一个面向开发者和安全分析师的 **AI 代码漏洞扫描平台**。用户可以粘贴代码、上传文件、输入 URL 或 GitHub 仓库地址，由本地部署的 AI 模型（如 qwen2.5-coder-7b）进行漏洞检测，输出风险等级、漏洞类型、CWE 编号和修复建议。

产品气质：**专业、精密、克制**。参考 Stripe Dashboard 的数据密度与留白、Linear 的动效克制、Vercel 的极简美学。不是花哨的营销页，是每天都要用的专业工具。

技术栈：纯 HTML + Tailwind CSS + 原生 JS，无框架。深色模式为默认。

## 页面 1：仪表盘

**用途**：总览安全状态，一眼看清关键指标和趋势。

### 页头
- 标题 "仪表盘" + 后端连接状态指示器（绿点 + "后端已连接 · qwen2.5-coder-7b"）
- 副标题："实时掌握代码安全状态与扫描趋势"

### KPI 核心指标区（4 张卡片横排，自适应网格）
每张卡片包含：顶部一行（icon + 标签），下方一行（大数字 + 副信息）。数字要大（48px+），标签要小（12px），形成强对比。

1. **本月扫描** — 数字 1,284 — 副信息 "次扫描" — icon: 活动图标（蓝色）
2. **高危漏洞** — 数字 23 — 副信息 "待修复" — icon: 警告三角（红色）— 数字用红色
3. **修复率** — 数字 87% — 副信息 "较上月 +5%" — icon: 勾选圆圈（绿色）
4. **平均风险分** — 数字 5.4 — 副信息 "/10" — icon: 仪表盘（黄色）

### Bento 主区（2:1 网格，左侧 2fr 三个卡片，右侧 1fr 侧栏）

**左侧主区（3 张卡片）**：

1. **风险分布 donut 图**
   - 原生 SVG 环形图，4 段：高危(红) / 中危(黄) / 低危(绿) / 信息(蓝)
   - 中心显示总数 + "风险"
   - hover 某段时：该段加粗描边 + 外发光，中心文字切换为该段百分比，右侧图例联动高亮
   - 右侧图例列表：色块 + 标签 + 百分比

2. **扫描趋势折线图（近 7 日）**
   - 原生 SVG 折线图，带渐变面积填充
   - X 轴日期标签，Y 轴最大值标注
   - 数据点圆点

3. **最近动态列表**（横跨两列）
   - 5-8 条记录，每条：风险徽章（左边框 + 文字色，无彩色背景块）+ 文件名（等宽字体）+ 漏洞类型 + 相对时间
   - 例如："在 user_auth.py 发现 SQL 注入 — 3 小时前"

**右侧侧栏**：

4. **快捷入口**
   - 3 个入口卡片：粘贴代码分析 / 上传文件扫描 / GitHub 仓库安全态势
   - 每个入口：icon 方块(40px) + 标题 + 副标题 + 右箭头
   - hover 时边框变主色、背景微变

## 页面 2：扫描工作台

**用途**：核心操作页，输入代码 → 执行扫描 → 查看结果。

### 布局（左右分栏）

**左侧输入面板**：

- 标题 "新建扫描"
- **5 个输入方式 Tab**（带滑动指示器）：
  1. **粘贴代码** — 语言选择下拉 + 多行代码输入框（等宽字体，placeholder 展示 SQL 注入示例）
  2. **上传文件** — 拖拽区（虚线边框 + 上传 icon + "拖拽文件到此处或点击选择"）+ 已选文件列表
  3. **URL** — 单行输入框，输入 API 地址
  4. **GitHub** — 仓库地址输入框 + 最大文件数输入框（默认 20）
  5. **快速演示** — 漏洞样本下拉选择 + 样本元信息（CWE 编号 / 预期结果 / 说明）+ "加载示例" 按钮

- **高级选项**（可折叠）：
  - 多模型对比开关 — 开启后显示模型多选列表
  - 启用外部工具开关 — 开启后显示工具信息

- **引擎状态栏**：显示当前引擎名称 + 连接状态圆点（绿/红）

- **扫描进度条**（扫描时显示）：状态文字 + 百分比 + 进度条填充动画。资源紧张时显示黄色警告横幅。

- **开始分析按钮**（主色，全宽）

**右侧结果面板**：

- 标题 "检测结果" + 结果计数 "共 N 项"
- **严重级别筛选器**：全部 / 严重 / 高危 / 中危 / 低危 / 信息（圆角筛选片，激活态放大+主色）
- **下载报告按钮**（导出 Markdown）
- **结果卡片列表**：每张卡片显示：
  - 文件名（等宽字体）+ 风险等级徽章
  - 漏洞类型 + CWE 编号
  - 漏洞代码片段（代码高亮，等宽字体，红色边框）
  - AI 分析说明
  - 修复建议 + 安全代码示例（绿色边框）
  - 展开收起交互
- **空状态**：虚线边框 + 提示文字
- **扫描中状态**：加载动画 + 提示

**底部报告历史**：
- 标题 "报告历史" + "本地持久化，刷新不丢" + 清空按钮
- 历史记录列表

## 页面 3：CWE 样本库

**用途**：漏洞类型知识库，浏览和学习常见漏洞模式。

### 页头
- 标题 "CWE 样本库"
- 副标题统计："共 N 个 CWE · 显示 N 个" + 检测摘要

### 搜索与筛选
- 搜索框："搜索 CWE ID、名称或关键词..."
- 严重级别筛选片

### CWE 卡片网格（自适应，每张卡片）
- CWE 编号（等宽字体，主色，如 "CWE-89"）
- 严重等级徽章
- 漏洞名称（如 "SQL 注入"）
- 简短描述
- "查看详情" 链接

### CWE 详情弹窗（点击卡片打开）
- 顶部：CWE 编号 + 严重等级徽章 + 分类 + 关闭按钮
- 漏洞名称（大标题）
- **漏洞描述**
- **检测要点**
- **漏洞代码示例**：语言标签 + 代码块（红色调）
- **安全代码示例**：语言标签 + 代码块（绿色调）
- **修复建议**
- **适用语言标签**（Python / Java / JavaScript / PHP 等）

## 页面 4：安全态势

**用途**：仓库级安全评估，综合评分和修复优先级。

### 仓库输入区
- 仓库地址输入框（placeholder: "github.com/owner/repo"）
- "分析仓库" 按钮（主色）

### 元信息栏
- 仓库名称 · 分析时间 · 扫描文件数

### 综合风险评分区
- **评分环**（大圆环 SVG）：0-100 分，带呼吸动画。中心显示分数（大数字）+ 等级标签（如 "中等风险"）
- 评分描述文字

### 漏洞统计区（5 个数字卡片）
- 总计 / 严重 / 高危 / 中危 / 低危 / 信息 — 每个数字用对应语义色

### 图表区（2 张卡片）
1. **严重等级分布柱状图**：5 根柱子（严重/高危/中危/低危/信息），hover 时柱子上浮+提亮
2. **近 7 天风险评分趋势折线图**

### 优先修复清单（表格）
- 列：文件 / 漏洞类型 / 风险等级 / CWE / 建议
- 行 hover 高亮
- 按风险等级排序（严重在前）

## 设计约束（给 Stitch 的提示）

1. **深色模式为默认**，背景接近纯黑(#0d0d0d)，卡片深灰
2. **主色**：深色模式用红色系(#fc2c50)，浅色模式用蓝色系(#4285f4)
3. **状态色**：success(绿) / warning(黄) / error(红) / info(蓝)，只用于 icon、小圆点、徽章左边框，不要整块彩色背景
4. **字体**：DM Sans(UI) + JetBrains Mono(代码/数据) + 中文回退 Noto Sans SC
5. **卡片层次**：主卡片更实(高不透明度)，次卡片更透(低不透明度)，建立视觉主次
6. **动效克制**：评分环可保留呼吸动画，卡片 hover 微位移(-2px)，不要 3D 倾斜，不要 idle 浮动
7. **排版拉差**：关键数字大(48px+)，标签小(12px)，形成强对比
8. **间距放开**：卡片间距 20px+，区块间距 32px+，留白占画面 40%+
9. **无图表库**：所有图表用原生 SVG 实现
10. **响应式**：1024px 以下网格降为单列
