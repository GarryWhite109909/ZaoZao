## 四、截取通用要求

- **格式**：图片 PNG；动效 GIF；
- **主题**：建议深色主题（或深浅各截一张备选）；
- **分辨率**：满足**打印可读**（≥150 DPI 等效，不要截得过小）；
- **命名口径**：界面文字与全书一致（软件名「凿凿 / ZaoZao」）；
- **匿名**：截图中不得出现真实姓名、学校信息、个人仓库地址（若界面显示了 GitHub 仓库地址，请使用示例仓库）。
