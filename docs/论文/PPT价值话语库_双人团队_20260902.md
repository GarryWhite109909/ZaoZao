### 2.2 自研深度——零依赖，一行行写的

**主话语**

> "8 个核心工具里 7 个零第三方依赖、从零手写：自研污点分析、自研 AST 切片、
> 自研手写括号深度匹配的 JSON 状态机、自研 CWE/行号双纠正器。
> 我们不是在拼装开源件，是在补 LLM 落地链路上缺失的每一块。"

**支撑点（挑 2~3 个放页面）**
- **TaintTracker**：基于 tree-sitter 的轻量污点分析，5 种语言、跨语言语义消歧
  （JS 的 `exec(` 是命令注入、Python 的 `exec(` 是代码注入）、框架注解自动识别 source
- **约束解码兜底 + 手写 JSON 状态机**：模型输出解析失败从 **18/87 降到 0/87**
- **CWE Normalizer / LineNormalizer**：零 token 开销的后处理纠正——"语义对但编号记错"、
  "行号数错但内容对"都被确定性修复，不花模型一个 token
- **提示质量审计器**：把"工具提示到点没到点"从感觉变成五维量化指标

### 2.3 工程判断力——细节里的取舍

**主话语**

> "工程素养不在功能列表里，在取舍里：宁可用 501 告诉前端'此功能后端不支持'，

## 五、方法论层：探索与实践

### 5.1 主话语（对应 PPT 第一幕"方法论发现链"）

**主话语**

> "这个项目最值钱的产出不只是模型，而是一套'如何让自己不上当'的方法论：
> 三次主动揪出三类泄漏、四条评估铁律、一条归因分流原则——每一次都是先推翻自己，再沉淀成制度。"

**方法论四件套（每条一句话，配一个真实事故做证据）**
1. **数据可信度先行**：三次泄漏（答案注释 / RAG 示例雷同 / 训练-测试 Jaccard）全部主动排查发现，
   v2 的"89.7%"是假象、修复后掉到 78.2%——**我们公开把自己最好看的数字证伪了**
2. **归因分流**：同一个错判，工具问题修规则、模型问题归训练，禁样本特判；
   "工具链 recall 0.864 < 纯 LLM 0.967"时我们没有推翻架构，逐样本归因后确认是工具提示误导模型
3. **评估隔离**：带反馈回路的系统会"自我污染"（抑制池跨跑累积、共形校准 in-sample 泄漏），
   评估强制 `--no-signal-feedback`——fixed3 的虚高数字被我们自己作废
4. **规则先于结果**：新增任何规则前先问"不看测试集结果我能推出来吗？否 → 删"——
   08-17 一条"类型白名单"规则在评审中被我们自己识别为"变相答案泄漏"并废弃

### 5.2 从 bug 里长出来的方法论

**主话语**

> "两阶段在真实 CVE 上 recall 只有 0.556 时，第一直觉是'工具零覆盖、架构要改'。
> 我们没有急着改架构，而是先查代码接缝——结果是一个解析器分支从未实现（注释谎称'双格式兼容'）。
> 修复后 recall 0.556 → 0.882。**归因先于动手，这条教训我们写进了开发规范。**"

**支撑点**
- 沉淀成文的方法论文档：`方法论_工具模型自适应闭环.md`（4.8 万字）、
  `方法论_Nivis-α1训练.md`、`方法论_注意力预算与工具盲区提醒.md` 等——方法论不是口号，是 47 份文档里的常驻章节

## 六、严谨实验设计层

### 6.1 主话语

**主话语**

> "repeat=1 的结论被 repeat=3 推翻过一次之后，我们的规矩变成了：
> 所有结论必须带置信区间，所有'最优'必须注明口径与基座。"

**支撑点（挑 3~4 个放页面）**
- **统计纪律**：repeat=3 多数表决 + 95% 置信区间 + 配对 block Bootstrap（N=10000）
- **双口径评估**：loose（判对就行）与 strict（CWE 编号也要对）并行——
  strict 口径揭穿了 loose 口径的虚高（"判别与格式收益 ≠ 归因能力"的结论就是这么来的）；
  loose 与 strict 甚至给出不同的"最优 prompt 变体"，引用必须注明口径
- **G0 方法学修复**：9 项方法学问题（文件名泄漏答案、repeat 默认值、平票语义等）一次性修复，
  **所有受影响实验全部重跑**——exp_01 从"100%"诚实降到"92.9%"
- **没人度量过的组件也要度量**：预筛层从未被独立评估，我们专门建了评估：
  87 段 coverage 13.8%、被调用子集 strict 准确率 0.9167、"零误报直判"——
  "宁可漏判不可误判"的设计目标第一次拿到量化证据
- **消融做到反直觉结论也照登**：RAG 四组对照（真 RAG / 纯 LLM / 随机文本 / 无关文本）发现
  RAG 不升反降（A<B 且 A<D）——结论照发："RAG 价值是可解释性，不是纠错"
- **失败是一等公民**：13+ 条失败教训全部落档（每条有根因、修复、来源文件），
  DPO 三次 OOM、CPT 知识冲突、LoRA 增容无效……都写进了论文素材
