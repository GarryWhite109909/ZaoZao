# 蒸馏产出对账：682 块产出跑到哪里去了（v2_17 → v2_19）

> 回应「17 也有 10000 多，19 对比 17 就多几十条，这么些天蒸的哪里去了」。

## 一、先纠正度量口径：行数不是蒸馏产出的度量

`v2_17_clean 10022 → v2_19 候选 10069 = **净 +47 行**` —— 但这个数**完全不能用来衡量蒸馏产出**，因为组装器的"替换"是**原地换文本，行数不变**：

| 去向 | 条数 | 对行数的贡献 |
|---|---|---|
| 同码替换（用新蒸块换掉旧行文本） | **289** | **0** |
| 新增行（基座没有同码） | **51** | +1 each |
| **由新蒸馏块生成的文本行合计** | **340** | 只显示成 +47 |

**所以这批蒸馏真正进库的是 340 行（占 10069 的 3.4%），不是 +47。** 剩下 9729 行仍是基座旧文本。

## 二、产出对账：682 块 → 554 个唯一键 → 340 键入册 / 266 键被挡

| | 数量 |
|---|---|
| wave1 三批蒸馏块（9_11批 226 + 续投批 251 + 复核批 32，剔除自查伪块） | **504 块** |
| wave2 预审 + 正式块（122 + 61） | **178 块** |
| **产出总量** | **682 块** |
| 去重后的唯一键（wave1 462 键 + wave2 92 键） | **≈ 554 键** |
| **入册** | **340 键**（替换 289 + 增补 51） |
| **被挡在门外** | **266 键** |

### 266 键被挡住的原因（v2_19 组装器计数，逐项）

| 去向 | 键数 | 判据 |
|---|---|---|
| `跳:同码行保留(未达替换判据)` | **113** | 新蒸与旧行**同判**，但 CWE 与 manifest 期望不在同一族 → 弃用 |
| `争议:新旧结论相反(9_11批)` | 46 | 新旧结论相反 → 维持旧行 |
| `争议:新旧结论相反(续投批)` | 44 | 同上 |
| `争议:新旧同判但cwe不符(续投批)` | 19 | CWE 编号分歧 → 维持旧行 |
| `跳:kit被治理剔除` | 18 | kit 级剔除（已从 200 降到 18） |
| `留:无新蒸块` | 21 | 这些键根本没有块 |
| 其他争议（复核批与真值反 2 / cwe 不符 1 / 结论不可解析 2） | 5 | —— |
| **合计** | **266** | |

**一句话：蒸馏产出没丢，是组装器的三条判据把它挡在门外了** ——
① "与旧行同判但 CWE 族不符"（113 键）
② "新旧结论相反"（90 键：46+44）
③ "kit 被治理剔除"（18 键，重建前是 200 键）

## 三、另外还有两个被浪费的地方

1. **wave2 预审 122 块从头到尾没被任何组装读过**（组装器只读正式产出那 5 个文件）。它覆盖 46/46 对、含 441 全部形态。
2. **wave2 正式只覆盖 28/46 对**，另 18 对无正式产出；其中 `441-09/10`、`78-S-09/09b` 是 PASS 却没有块。

## 四、还有一个必须说的事实：这批"蒸了很多"里有相当一部分是**重蒸**

- wave1 三批覆盖 **232 个 kit**、去重后 **462 键**，但产出 **504 块** → 约 **42 块是同键重复蒸**（复核批的 `L56`/`L68` 锚点单元、同窗口多候选）。
- 更值得注意的是：**9_11批（218 键）与续投批（244 键）居然完全不重叠**（218+244 = 462 = 并集）—— 说明这两批是**按不同 kit 分片**蒸的，不是重复劳动。这是好事。
- 复核批的 31 键里有 31 个与 9_11批 重叠（`该键以复核批为准(9_11批块弃用) 31`）—— 这是**刻意的双蒸复核**，也不算浪费（复核批是裁决权威）。

## 五、结论

| 问 | 答 |
|---|---|
| 这些天蒸的哪去了？ | 340 键进库（挂在 289 条替换 + 51 条新增上）；**266 键被三条判据挡住**；另有 wave2 预审 122 块从未被读 |
| 为什么行数只涨 47？ | **度量错觉**。替换不增行。看行数会系统性低估蒸馏产出约 7 倍（47 vs 340） |
| 蒸馏是不是白蒸了？ | 不是白蒸，是**管道只开了半扇门**。要全用上，需改组装器三条判据——那三条都是"标签一致性"判据，不是"样本质量"判据，与你的入库口径冲突 |

## 六、要动的话，动这三处（预计回收 ~240 键）

1. **取消"CWE 族校验"作为替换门槛**（挡住 113 键）→ 改为"只要新蒸块产物合格就替换，CWE 分歧记台账"。
2. **取消"新旧结论相反 → 维持旧行"**（挡住 90 键）→ 改为"两边都保留为候选，按产物质量选一条"。
3. **把 wave2 预审 122 块接入组装管道**（覆盖 46/46 对）。
