 113| // IsSafe reports whether the reference name can be safely turned into a path
 114| // under the .git directory, mirroring Git's refname_is_safe (refs.c). A name
 115| // is safe when it is either:
 116| //
 117| //   - under "refs/", non-empty after the prefix, containing no backslash and
 118| //     no empty, "." or ".." path component (so it cannot escape the refs/
 119| //     sub-tree, or alias another name, once turned into a path); or
 120| //   - a one-level pseudo-ref whose spelling is restricted to [A-Z_]
 121| //     (e.g. HEAD, ORIG_HEAD, FETCH_HEAD).

 123| // Everything else — a lowercase or mixed one-level name such as "config" or
 124| // "index", an absolute or drive-prefixed name, or a refs/ name that escapes —
 125| // is unsafe, because it could resolve onto unrelated repository metadata.

 130| 	}
