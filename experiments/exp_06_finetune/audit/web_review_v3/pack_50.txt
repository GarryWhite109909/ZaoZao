  29| // repositoryPattern matches a single no-argument Gradle repository declaration of the form
  30| // "name()" (e.g. "mavenCentral()"). Repository values are rendered verbatim into the
  31| // generated build.gradle, so the value must not be able to express arbitrary Groovy that
  32| // Gradle would execute during its configuration phase (GHSA-3v79-m2cg-89ww). Permitting only
  33| // a bare "name()" call - no ".", no arguments, no string-delimiter characters - means no
  34| // method chain, command string or block break-out can be formed, while every documented
  35| // repository shortcut (mavenCentral(), jcenter(), google(), mavenLocal(),
  36| // gradlePluginPortal()) is accepted. Surrounding whitespace is trimmed before matching.
