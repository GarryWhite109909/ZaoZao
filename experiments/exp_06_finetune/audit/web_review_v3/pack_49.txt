2. 第 94 行使用 `Environment(extensions=settings.DOCXTEMPLATE_JINJA_EXTENSIONS)` 创建环境。Jinja2 的普通 `Environment` 不做任何沙箱隔离，模板表达式可以访问对象的魔术属性（如 `__class__`、`__mro__`、`__subclasses__` 等）。

3. 数据流路径为：用户上传/编辑的 docx 模板（内含 Jinja2 表达式）-> `docxtpl` 使用第 94 行返回的环境渲染模板 -> 模板中的表达式在非沙箱环境中求值 -> 攻击者通过 `{{ ''.__class__.__mro__[1].__subclasses__()... }}` 类 payload 触达 Python 运行时，实现任意代码执行。

4. 文件中注册的过滤器（第 83–89 行，如 `dateformat`、`image`）均未对模板语法本身做任何限制；`image` 过滤器（第 61 行起）只校验图片格式，与模板表达式注入无关，不能缓解 SSTI。
