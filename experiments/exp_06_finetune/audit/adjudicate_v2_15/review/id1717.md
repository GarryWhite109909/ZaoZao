# id=1717 审察稿（java，63 行）

> 审计疑点：CSRF 技术上可辩护但超污点流框架；正文含参数化日志错误断言与系统性行号漂移

## 教师分析

**分析过程：**

1. **第36行**：`String action = request.getParameter("action");` 从请求中直接获取参数，未校验 `Origin` 或 `Referer` 头。
2. **第41行**：`executeAdminAction(action)` 执行敏感管理操作（如删除用户、重置配置），仅依赖会话中的角色校验。
3. **第45-49行**：日志记录中直接拼接来自请求的参数 `action` 和会话 ID，形成日志注入（CWE-117 Improper Output Neutralization for Logs
4. **第52行**：响应直接返回 "Action processed"，无 CSRF token 验证，攻击者可通过 `<form>` 或 `fetch` 跨域提交，浏览器自动携带 Cookie，导致 CSRF 漏洞成立。
5. **第53行**：`executeAdminAction` 无幂等性检查，重复请求可重复执行破坏性操作，放大 CSRF 影响。

```fix
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import javax.servlet.http.HttpSession;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.logging.FileHandler;
import java.util.logging.Level;
import java.util.logging.Logger;
import java.util.UUID;

public class LogServlet extends javax.servlet.http.HttpServlet {
    private static final Logger logger = Logger.getLogger("AuditLog");
    private static FileHandler fileHandler;

    static {
        try {
            fileHandler = new FileHandler("audit.log", true);
            logger.addHandler(fileHandler);
        } catch (IOException e) {
            logger.log(Level.SEVERE, "Failed to init log handler", e);
        }
    }

    protected void doPost(HttpServletRequest request, HttpServletResponse response) throws IOException {
        HttpSession session = request.getSession();
        String sessionId = session.getId();
        
        // 获取当前用户角色
        String userRole = (String) session.getAttribute("role");
        if (userRole == null || !userRole.equals("admin")) {
            response.sendError(HttpServletResponse.SC_FORBIDDEN, "Admin only");
            return;
        }

        // CSRF 防护：验证同步 token
        String expectedToken = (String) session.getAttribute("csrfToken");
        if (expectedToken == null) {
            expectedToken = UUID.randomUUID().toString();
            session.setAttribute("csrfToken", expectedToken);
        }
        String actualToken = request.getParameter("csrfToken");
        if (actualToken == null || !actualToken.equals(expectedToken)) {
            response.sendError(HttpServletResponse.SC_FORBIDDEN, "Invalid CSRF token");
            return;
        }

        // 关键操作
        String action = request.getParameter("action");
        if (action == null || action.isEmpty()) {
            response.sendError(HttpServletResponse.SC_BAD_REQUEST, "Missing action");
            return;
        }

        // 执行管理操作（如删除用户等）
        boolean success = executeAdminAction(action);

        // 记录审计日志（避免日志注入：使用参数化占位符，并过滤换行）
        String sanitizedAction = action.replaceAll("[\\r\\n]", "_");
        if (success) {
            logger.log(Level.INFO, "Admin action completed: {0} by session {1}", 
                       new Object[]{sanitizedAction, sessionId});
        } else {
            logger.log(Level.WARNING, "Admin action failed: {0} by session {1}", 
                       new Object[]{sanitizedAction, sessionId});
        }
        response.setContentType("text/plain");
        PrintWriter out = response.getWriter();
        out.println("Action processed");
    }

    private boolean executeAdminAction(String action) {
        // 模拟执行管理操作
        return "deleteUser".equals(action) || "resetConfig".equals(action);
    }
}
```
