## 1. ShowPrettyFormatLogToList（第 24–33 行）
- **入口/source**：参数 `revisionRange`（第 25 行），由上层路由（如 compare/diff、commit 范围查询）传入，通常来自 URL 查询参数（如 `?from=...&to=...`）。
- **sink**：第 27 行 `AddDynamicArguments(revisionRange)` 后在第 29 行 `RunStdBytes(ctx)` 执行 `git log`。
- **防御验证**：`AddDynamicArguments` 仅把字符串作为单个 argv 元素传入（无 shell 注入），但**没有经过 `AddDashesAndList` 的 `--` 分隔保护**。若调用方未校验，攻击者可传入以 `-` 开头的值（如 `--output=/tmp/x` 或其他 git log 选项），被 git 解释为选项而非 revision —— 典型 **CWE-88 参数注入**。注释（第 26 行）只处理了歧义报错，不是安全过滤。
