## 入口点枚举

## 数据流验证

- **字段白名单**：第 105 行 `only($setting, ['id', 'name', 'value'])` 只保留三个键，防止批量赋值写入任意列。
- **XSS 防御**：
  - 第 91-95 行：以 `label_custom_field_` 开头的 name → `strip_tags`；
  - 第 97-102 行：富文本设置名（`disable_booking_message`）→ `pure_html`。
  - **注意**：其余任意自定义设置名的 value **未做净化**即入库。但该写入需要管理员级权限（PRIV_SYSTEM_SETTINGS edit），属于“管理员可存富文本”的设计行为，且读取端是否转义不在本文件内。按“黑名单/部分过滤不算有效防御”的标准，此处对非白名单设置名的 value 存在存储型 XSS 的潜在通道——但前提是攻击者已是高权限管理员，通常视为可信操作者，风险极低。
