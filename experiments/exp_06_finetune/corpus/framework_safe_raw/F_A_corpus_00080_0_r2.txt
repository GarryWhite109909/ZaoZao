```python
from flask import Flask, request, jsonify
import hashlib

app = Flask(__name__)

@app.route('/api/sign', methods=['POST'])
def sign_payload():
    parts = request.get_json().get('parts', [])
    if not parts:
        return jsonify({'error': 'no input'}), 400
    # prefix with block count to prevent hash collisions
    data = str(len(parts)).encode()
    for p in parts:
        data += p.encode() + b'$'
        data += str(len(p.encode())).encode()
    digest = hashlib.sha256(data).hexdigest()
    return jsonify({'signature': digest})

if __name__ == '__main__':
    app.run()
```

2. 第 10-14 行将用户可控的 `parts` 拼接进字节串 `data`（含长度前缀防碰撞拼接逻辑），数据流保持原样未改动。
3. 第 15 行为 sink：`hashlib.md5(data)` 对攻击者可控输入计算 MD5。MD5 已被证实存在碰撞与长度扩展类弱点，用于生成签名属于 CWE-327 破损/风险加密哈希。
4. 防御修复：仅将第 15 行替换为 `hashlib.sha256(data).hexdigest()`。SHA-256 属于当前无已知实用碰撞攻击的标准安全哈希；接口签名场景只需抗碰撞性，无需 HMAC 密钥即可满足防御有效性；替换发生在 sink 处，位置正确、类型正确（同为 hashlib 的 hexdigest 接口），且覆盖了该函数中唯一的哈希调用点，攻击面完整。
