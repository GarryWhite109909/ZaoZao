```python
import ipaddress
import socket
from urllib.parse import urlparse

import requests
from flask import Flask, request, jsonify

app = Flask(__name__)

BLOCKED_NETS = [
    ipaddress.ip_network('10.0.0.0/8'),
    ipaddress.ip_network('172.16.0.0/12'),
    ipaddress.ip_network('192.168.0.0/16'),
    ipaddress.ip_network('127.0.0.0/8'),
    ipaddress.ip_network('169.254.0.0/16'),
    ipaddress.ip_network('100.64.0.0/10'),
    ipaddress.ip_network('0.0.0.0/8'),
    ipaddress.ip_network('240.0.0.0/4'),
]


def is_private_ip(addr):
    try:
        ip = ipaddress.ip_address(addr)
    except ValueError:
        return True
    return any(ip in net for net in BLOCKED_NETS)


@app.route('/fetch')
def fetch_url():
    target = request.args.get('url', '')
    parsed = urlparse(target)
    if not parsed.hostname:
        return jsonify(error='invalid url'), 400

    # SSRF guard: resolve hostname and reject private addresses
    resolved = {ai[4][0] for ai in socket.getaddrinfo(parsed.hostname, None)}
    if any(is_private_ip(a) for a in resolved):
        return jsonify(error='blocked host'), 403

    # DNS rebinding defense: pin the validated IP for the actual request,
    # so the second resolution inside requests cannot return a private address.
    pinned_ip = sorted(resolved)[0]
    safe_url = target.replace(parsed.hostname, pinned_ip, 1)
    resp = requests.get(safe_url, timeout=5, headers={'Host': parsed.hostname})
    return jsonify(status=resp.status_code, body=resp.text[:2000])


if __name__ == '__main__':
    app.run()
```

2. 第 36-38 行：原代码先解析 DNS 并用 `is_private_ip` 校验（第 39 行），但第 41 行 `requests.get(target)` 会再次独立解析 DNS——TOCTOU 窗口使攻击者可用 DNS rebinding 让第二次解析返回内网地址，绕过校验直达 sink。
3. 第 42-44 行修复：将已通过白名单校验的 IP 固定（pin）进实际请求 URL，并用 `Host` 头保留原主机名。类型正确性：`pinned_ip` 来自同一 `resolved` 集合，是已验证的合法公网地址字符串；位置正确性：防御位于 sink 调用前、复用同一校验结果，消除二次解析；攻击面覆盖：requests 不再触发新的 DNS 查询，rebinding 攻击面被完全关闭。
4. 第 45-46 行数据流走向不变：仍以 `resp.status_code` / `resp.text[:2000]` 返回，业务语义保持一致。
5. 第二入口检查：应用仅注册 `/fetch` 一个路由，无其他读取 `url` 参数或发起出站请求的通道；`is_private_ip` 与 `BLOCKED_NETS` 白名单式拒绝逻辑未改动。
