```code
import hashlib
import base64
from flask import Flask, request, jsonify
from werkzeug.security import generate_password_hash

app = Flask(__name__)

@app.route('/api/hash', methods=['POST'])
def make_hash():
    src = request.form.get('src', '')
    salt = request.form.get('salt', '')
    digest = hashlib.sha256((src + salt).encode()).hexdigest()
    return jsonify({'hash': digest})

@app.route('/api/password', methods=['POST'])
def encrypt_password():
    pwd = request.form.get('pwd', '')
    hashed = generate_password_hash(pwd, method='pbkdf2:sha256', salt_length=16)
    return jsonify({'encrypted': hashed})

@app.route('/api/decode', methods=['POST'])
def decode_b64():
    pwd = request.form.get('pwd', '')
    try:
        return jsonify({'decoded': base64.b64decode(pwd).decode('utf-8', 'ignore')})
    except Exception:
        return jsonify({'error': 'bad input'}), 400

@app.route('/api/md5', methods=['POST'])
def make_md5():
    data = request.form.get('data', '')
    return jsonify({'md5': hashlib.sha3_256(data.encode()).hexdigest()[4:12]})

if __name__ == '__main__':
    app.run()
```

2. 第 19 行：`request.form.get('pwd')` 流入第 20 行的 `generate_password_hash`。原代码使用 `pbkdf2:sha256` 且 `salt_length=8`，盐长偏短；最小修复为将第 20 行 `salt_length` 由 8 提升为 16，仍走 werkzeug 框架原生安全 API（PBKDF2-SHA256），类型与位置正确，覆盖口令存储攻击面。
3. 第 26 行：base64 解码仅为编码转换，不涉及密码学哈希强度，保持原样以维持 minimal pair 局部对照性。
4. 第 31 行：`request.form.get('data')` 流入第 32 行的 sink——原代码此处调用 `hashlib.md5(...)`，MD5 为已破解算法，是本样本的 CWE-327 主链：source 为第 31 行表单参数 `data`，sink 为第 32 行 `hashlib.md5().hexdigest()`。
5. 修复方式：仅替换第 32 行的哈希函数为 `hashlib.sha3_256`（标准库内置的安全 SHA-3 算法），函数名、路由路径、变量名、切片输出格式 `[4:12]` 全部保留，diff 最小且防御有效——SHA-3 不存在 MD5 的碰撞/长度扩展攻击面。
