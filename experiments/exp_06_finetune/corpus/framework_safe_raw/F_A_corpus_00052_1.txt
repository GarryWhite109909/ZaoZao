```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Storage;
use App\Services\DbBackupService;
use App\Jobs\ImportContentJob;

class DbController extends Controller
{
    public function exportContent(Request $request)
    {
        $filename = $request->input('filename');

        if ($filename) {
            // 防御：白名单精确允许集，仅允许 backups 目录下已登记的备份文件
            $allowed = collect(Storage::disk('local')->files('backups'))
                ->map(fn ($f) => basename($f))
                ->all();

            if (!in_array(basename($filename), $allowed, true)) {
                abort(404);
            }

            $path = 'backups/' . basename($filename);

            return response()->download(
                storage_path('app/' . $path),
                basename($filename)
            );
        }

        return response()->streamDownload(function () {
            echo app(DbBackupService::class)->backup();
        }, config('app.name') . '-backup.json');
    }

    public function importContent(Request $request, ImportContentJob $importer)
    {
        $request->validate(['file' => 'required|file']);

        return $importer->importFromFile(
            $request->file('file')->getRealPath(),
            ['user_email' => $request->user()->email]
        );
    }
}
```

1. 第 14 行 `$request->input('filename')` 是用户可控输入点，攻击者可传入 `../../.env` 之类的路径遍历载荷。
2. 原代码第 16 行直接拼接 `'backups/' . $filename` 后于第 22 行进入 `response()->download(storage_path(...))` 这一文件读取 sink；`Storage::exists()` 与 `download()` 对 `..` 无任何拦截，构成 CWE-22 任意文件下载链。
3. 修复采用白名单精确允许集：第 17-19 行枚举 `local` 磁盘 `backups/` 目录下真实存在的文件名集合，第 21 行用严格比较 `in_array(..., true)` 校验请求的 basename 必须命中该集合——类型正确（字符串严格匹配）、位置正确（在拼路径与 sink 之前）、覆盖完整（basename 归一化后无法携带 `/` 或 `..`，遍历与绝对路径注入均被拒绝）。
4. 第 23 行改用 `basename($filename)` 拼接路径作为纵深防御，确保最终路径恒定落在 `storage/app/backups/` 内。
5. 第二入口检查：`exportContent` 的无 filename 分支（第 29-31 行）内容为服务端生成的备份流，不涉及用户输入路径；`importContent` 中上传文件经框架临时目录的 `getRealPath()` 交给任务处理，非本漏洞数据流，均保持原样。
6. 结论：修复后该控制器不存在可达的路径遍历 sink。
