```code
from flask import Flask, request, render_template_string, make_response
import html

app = Flask(__name__)

# 白名单：仅允许这些标签名被序列化（精确允许集，而非黑名单）
ALLOWED_TAGS = {"div", "span", "p", "h1", "h2", "h3", "ul", "ol", "li", "b", "i", "em", "strong", "style"}

def escape_html(s):
    # 使用标准库 html.escape 做完整转义（含引号），替代手写部分转义
    return html.escape(s, quote=True)

def serialize_node(tag, attrs, children):
    out = "<" + tag
    for k, v in attrs.items():
        out += ' ' + k + '="' + escape_html(v) + '"'
    out += ">"
    inner = "".join(children)
    # 修复点：raw-content 元素内部同样做完整 HTML 转义，
    # 不再依赖"只转义父级闭合标签"的不完整处理；
    # style 等原始内容元素若需保留 CSS，由调用方保证内容为受控常量，
    # 用户输入一律经过完整转义后输出。
    out += escape_html(inner)
    out += "</" + tag + ">"
    return out

@app.route("/render")
def render_page():
    # source: user-controlled markup fragments
    user_tag = request.args.get("tag", "div")
    user_content = request.args.get("content", "")
    style_body = request.args.get("style", "")
    # 白名单校验标签名，非法值回退到 div
    if user_tag not in ALLOWED_TAGS:
        user_tag = "div"
    node = serialize_node(user_tag, {}, [user_content])
    # 用户提供的 style 内容同样完整转义后再进入 raw-content 元素
    style_node = serialize_node("style", {}, [escape_html(style_body)])
    html_out = "<html><body>" + node + style_node + "</body></html>"
    resp = make_response(render_template_string(html_out))
    resp.headers["Content-Type"] = "text/html"
    return resp

if __name__ == "__main__":
    app.run()
```

3. 第 24-25 行对 `user_tag` 施加白名单精确允许集校验，防止注入任意标签名（如 `script`、`iframe`）。
4. 第 27-28 行删除原"只转义父级闭合标签"的不完整逻辑，raw-content 元素内部统一走第 12 行的完整转义 sink；用户传入的 `style_body` 在第 31 行先经 `escape_html` 再进入 `<style>` 序列化，堵住 `</style><script>` 类逃逸。
5. 攻击面覆盖检查：三条数据流（tag/content/style）全部收敛到同一转义 sink，无遗漏通道。
6. 第二入口检查：应用仅有 `/render` 一个路由，`render_template_string` 输入已全部转义，模板层不再引入未转义插值，无替代攻击通道。
