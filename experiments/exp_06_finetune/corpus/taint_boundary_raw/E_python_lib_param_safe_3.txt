```python
"""config_loader.py — 配置/清单文件解析模块。

被上层服务调用（例如后台任务消费外部提交的配置文件内容），
本模块不直接接触任何网络入口，仅通过函数参数接收文件内容。
"""

import html
import json
import re

# 仅允许的配置键白名单
_ALLOWED_KEYS = {"title", "description", "author"}
# 值长度上限，防止超长注入
_MAX_VALUE_LEN = 200


def render_config_summary(raw_content: str) -> str:
    """解析外部提交的 JSON 配置文本并渲染为 HTML 摘要片段。

    raw_content 由上层调用者传入，可能来自用户上传，
    必须按不可信数据处理。
    """
    try:
        config = json.loads(raw_content)
    except (json.JSONDecodeError, TypeError):
        return "<p class='error'>invalid configuration</p>"

    if not isinstance(config, dict):
        return "<p class='error'>invalid configuration</p>"

    parts = []
    for key, value in config.items():
        # 白名单校验：拒绝一切未登记的键
        if key not in _ALLOWED_KEYS:
            continue
        if not isinstance(value, str):
            continue
        if len(value) > _MAX_VALUE_LEN:
            continue
        # html.escape 将 < > & " ' 全部转义为 HTML 实体，
        # 确保值无法闭合标签或注入属性/脚本上下文
        safe_value = html.escape(value, quote=True)
        safe_key = html.escape(key, quote=True)
        parts.append(
            f"<dt>{safe_key}</dt><dd>{safe_value}</dd>"
        )

    return "<dl>" + "".join(parts) + "</dl>"
```

2. **source→sink 数据流**：第 24 行 `json.loads(raw_content)` 解析后得到 `config` 字典，其键与值均继承自外部输入；第 41~43 行将键和值经 f-string 内插进 HTML 字符串并在第 46 行返回给上层渲染——HTML 输出即 CWE-79 的 sink。

3. **防御一（白名单校验）**：第 33 行 `if key not in _ALLOWED_KEYS: continue` 只放行 title/description/author 三个固定键，攻击者无法引入任意属性名或结构；这是白名单而非黑名单，无法被枚举绕过。第 34~38 行还限制值必须是字符串且长度 ≤200，收窄攻击面。

4. **防御二（正确转义）**：第 40 行 `html.escape(value, quote=True)` 是 Python 标准库的原生安全 API，将 `< > & " '` 五个字符全部转为 HTML 实体，同时覆盖元素内容上下文（防 `<script>`）与属性上下文（防引号逃逸）；第 41 行对键同样转义。转义发生在数据进入 sink 的最后一步（位置正确），且对每个被渲染的键值对无遗漏地执行（覆盖完整）。正则过滤、字符串替换等可绕过手段均未使用。

5. **第二入口检查**：文件内仅此一个公开函数，无其他导出接口、无模块级副作用读取外部数据、无间接回调；`json.loads` 本身不执行代码，解析失败路径返回的是硬编码常量字符串，不含污点数据。所有到达 sink 的数据都经过上述两道防御。

6. **结论**：唯一 source（`raw_content` 参数）到唯一 sink（返回的 HTML 片段）之间有白名单 + `html.escape(quote=True)` 双重有效防御，类型正确、位置正确、覆盖全部攻击面，不存在漏洞。
