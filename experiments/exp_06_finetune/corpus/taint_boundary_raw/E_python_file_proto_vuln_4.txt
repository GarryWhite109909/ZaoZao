```python
"""数据导入适配器：解析外部系统导出的 JSONL 记录文件并回填回调地址。

本模块由上层导入服务调用，传入外部系统投递的记录文件路径。
"""
import json
import urllib.request


def _resolve_callback(raw):
    # 弱防御：仅拦截内网常见前缀，攻击者可用十进制 IP、DNS 重绑定绕过
    blocked = ("127.", "10.", "192.168.", "169.254.")
    for p in blocked:
        if raw.startswith(p):
            return None
    return raw


def import_records(path):
    """读取外部系统导出的记录文件，逐行解析并向记录中的 callback_url 发送确认。"""
    with open(path, "r", encoding="utf-8") as f:
        for lineno, line in enumerate(f, 1):
            line = line.strip()
            if not line:
                continue
            record = json.loads(line)  # 第 24 行：文件内容即污点源
            url = record.get("callback_url", "")
            safe_url = _resolve_callback(url)
            if safe_url is None:
                continue
            req = urllib.request.Request(safe_url, method="POST")  # 第 29 行：SSRF sink
            urllib.request.urlopen(req, timeout=5)  # 第 30 行：发起请求
    return True
```

2. 数据流：第 26 行 `record.get('callback_url')` 取出攻击者完全控制的 URL 字符串，直接进入 `_resolve_callback`。
3. 防御分析：第 16-21 行的黑名单仅用 `startswith` 匹配四个前缀，覆盖面极窄——可被 `0x7f000001` 十进制 IP、`[::ffff:127.0.0.1]` IPv6 映射地址、DNS 域名（重绑定到内网）、或 `http://user@127.0.0.1@evil.com` 式混淆轻易绕过，属可绕过弱防御，不构成有效防护。
4. Sink 可达：第 29 行将未净化的 URL 构造为 Request，第 30 行 `urllib.request.urlopen` 实际发起网络请求，污点数据无任何有效校验直达 sink，形成完整 source→sink 链。
