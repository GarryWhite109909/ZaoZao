```java
package com.example.scanner.controller;

import org.springframework.web.bind.annotation.*;
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.ArrayList;
import java.util.List;

@RestController
@RequestMapping("/api/projects")
public class ProjectScanController {

    // Scan workspace for serverless config files by shelling out to find
    @GetMapping("/scan")
    public List<String> scanWorkspace(@RequestParam("workspaceDir") String workspaceDir) {
        String rootDir = (workspaceDir == null || workspaceDir.isEmpty())
                ? System.getProperty("user.dir") : workspaceDir;

        List<String> results = new ArrayList<>();
        try {
            // Vulnerable: user-controlled path interpolated directly into shell command
            ProcessBuilder pb = new ProcessBuilder("/bin/sh", "-c",
                    "find '" + rootDir + "' -name 'serverless.yml' -not -path '*/node_modules/*'");
            Process proc = pb.start();
            BufferedReader reader = new BufferedReader(new InputStreamReader(proc.getInputStream()));
            String line;
            while ((line = reader.readLine()) != null) {
                results.add(line);
            }
        } catch (Exception e) {
            // swallow errors, return partial results like the original
        }
        return results;
    }
}
```

1. 第 17 行：`@RequestParam("workspaceDir")` 是 Spring 地道的请求参数绑定方式，外部 HTTP 输入直接进入方法参数，构成 source。
2. 第 20 行：仅做空值回退到当前目录，没有任何字符过滤、白名单或转义，攻击者可控内容原样保留。
3. 第 25-26 行：通过 `ProcessBuilder` 执行 `/bin/sh -c` 并用字符串拼接把 `rootDir` 嵌入命令，等价于原代码的 `execAsync(\`find "${rootDir}" ...\`)`，构成 sink。
4. 防御缺失分析：单引号包裹可被 `' ; rm -rf / #` 这类输入闭合绕过；没有使用参数数组形式（`ProcessBuilder("find", rootDir, ...)`）或任何校验，与原漏洞同样可被命令注入。
5. 攻击路径：GET `/api/projects/scan?workspaceDir=/tmp' ; cat /etc/passwd #` → 拼接后 shell 执行任意命令 → 结果甚至可能随响应返回。
