class Application(app.Application):
    def __init__(self, master, debug):
        super().__init__(master, debug)

    def _host_allowed(self, handler) -> bool:
        opts = handler.application.master.options
        host_header = handler.request.host.lower()  # Host 头（含端口）
        port = str(opts.web_port)
        if opts.web_host:
            return host_header == f'{opts.web_host}:{port}'.lower()
        # 绑定在所有接口时，拒绝指向本机回环地址的 Host，阻断经代理的绝对形式请求
        hostname = host_header.rsplit(':', 1)[0].strip('[]')
        return hostname not in ('127.0.0.1', 'localhost', '::1', '[::1]')

    def find_handler(self, request):
        handler = super().find_handler(request)
        if not self._host_allowed(handler):
            class _Rejected(tornado.web.RequestHandler):
                def get(self):
                    self.set_status(403)
                    self.write('forbidden')
            return _Rejected, {}
        return handler

## 漏洞版分析（4 步）

1. **输入点枚举与可达性**：入口为绑定在 `web_host:web_port` 的 tornado HTTP 服务。攻击者作为代理客户端，可通过代理服务器发送绝对形式请求（`GET http://127.0.0.1:8081/...`）或利用浏览器/DNS rebinding 使请求携带指向回环的 Host 头到达内部 API。
2. **信任边界缺陷**：`Application` 直接继承 `app.Application`，对每个请求不做任何 Host 校验；tornado 路由仅按路径分发，完全信任请求中的 Host/目标主机字段——这正是 CWE-441（Unintended Proxy / Intermediary）。
3. **第二入口/替代通道检查**：除直接 HTTP GET 外，WebSocket 升级请求、静态资源路径 `/static/...`、以及通过代理的 CONNECT 隧道均最终进入同一 `Application.find_handler` 分发逻辑，全部无校验；无任何防御层存在。
4. **结论**：攻击者可读取/修改流数据、调用清除或拦截等管理端点，形成完整攻击链：恶意客户端 → 代理/Host 头 → 内部 API。

## 安全版分析（4 步）

1. **唯一语义修正**：新增 `Application._host_allowed` 并在 `find_handler` 入口强制执行——显式绑定 `web_host` 时要求 Host 精确等于 `web_host:web_port`；绑定所有接口时拒绝 Host 指向 `127.0.0.1/localhost/::1` 的请求并返回 403。其余代码逐 token 相同。
2. **防御有效性验证**：绝对形式 URI 经代理转发时必然携带 `Host: 127.0.0.1:8081`，被白名单拒绝；DNS rebinding 场景下浏览器解析后 Host 为攻击域名+错误端口，同样不匹配被拒；直连合法 UI 访问 Host 与配置一致，正常放行。
3. **覆盖完整性说明**：所有请求类型（GET/POST/WebSocket 升级/静态资源）都必经 `find_handler` 这一分发单点，校验位于该单点之前，故不存在绕过通道；不依赖可伪造的 XFF 等头，仅依据服务端自身配置比对，无法被客户端操纵。
4. **残余风险**：若用户显式将 `web_host` 设为 `0.0.0.0` 等通配值且端口被外部可达，仍建议配合认证令牌，但本修正已消除 CWE-441 的混淆代理缺陷本身。
