```php
<?php
// cache_utils.php - 简易文件缓存工具（原生 PHP 脚本）

function searchFile(string $filename, array $paths): ?string {
    foreach ($paths as $path) {
        $full = rtrim($path, '/') . '/' . $filename;
        if (file_exists($full)) {
            return $full;
        }
    }
    return null;
}

// 根据请求参数生成缓存文件名并读取缓存内容
function getCacheFileName(): string {
    $key = $_GET['cache_key'] ?? '';          // 外部输入直接作为缓存键
    return sys_get_temp_dir() . '/cache_' . md5($key) . '.php';
}

function readCache(): string {
    $file = getCacheFileName();
    if (!is_file($file)) {
        http_response_code(404);
        return 'cache miss';
    }
    // 直接 include 缓存文件，缓存文件名由弱哈希的输入派生
    ob_start();
    include $file;                            // sink：包含由用户输入派生的路径
    return (string)ob_get_clean();
}

header('Content-Type: text/plain');
echo readCache();
```

1. 第 15 行是 source：`$_GET['cache_key']` 直接取外部请求参数，无任何白名单或格式校验。
2. 第 16 行用 `md5()` 派生缓存文件名——MD5 属于已破解的弱哈希（CWE-327 的核心），攻击者可离线碰撞/预计算，预测或伪造任意键对应的文件名。
3. 第 24 行将派生路径拼入 `include`，若攻击者能控制临时目录下同名文件（或借助会话/上传落盘），即可执行任意 PHP 代码。
4. 全程缺少 HMAC、随机盐或 `hash_equals` 类完整性校验，也没有对最终路径做 realpath 前缀检查，防御完全缺失。
5. 语义结构与原 beego 漏洞一致：用户可控 key → 弱哈希生成缓存文件名 → 文件操作 sink。
