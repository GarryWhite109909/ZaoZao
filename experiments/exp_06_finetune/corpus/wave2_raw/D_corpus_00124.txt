```code-vuln
package urlx

import (
	"net/url"
	"strings"
)

// IsSameSite 判断给定 URL 是否属于本站（用于 redirect_to 校验）。
func IsSameSite(raw string) bool {
	if raw == "" {
		return false
	}
	if strings.HasPrefix(raw, "/") && !strings.HasPrefix(raw, "//") {
		return true
	}
	u, err := url.Parse(raw)
	if err != nil {
		return false
	}
	host := u.Hostname()
	// 缺陷：仅做后缀匹配，攻击者可用 evil-github.com 或 github.com.evil.com 绕过
	return strings.HasSuffix(host, "github.com")
}
```
```code-safe
package urlx

import (
	"net/url"
	"strings"
)

// IsSameSite 判断给定 URL 是否属于本站（用于 redirect_to 校验）。
func IsSameSite(raw string) bool {
	if raw == "" {
		return false
	}
	if strings.HasPrefix(raw, "/") && !strings.HasPrefix(raw, "//") {
		return true
	}
	u, err := url.Parse(raw)
	if err != nil {
		return false
	}
	host := u.Hostname()
	// 修正：改为精确主机名白名单校验，杜绝子域/后缀混淆绕过
	return host == "github.com" || strings.HasSuffix(host, ".github.com")
}
```

**vuln 版分析**
1. 攻击者提交 `redirect_to=https://evil-github.com`。
2. `url.Parse` 成功解析，host 为 `evil-github.com`。
3. `strings.HasSuffix(host, "github.com")` 返回 true，校验被绕过。
4. 用户被重定向到任意外部站点，构成开放重定向。

```json
}
```

**safe 版分析**
1. 校验改为精确比较 `host == "github.com"`，或以 `.github.com` 结尾的合法子域。
2. `evil-github.com` 既不等于精确值也不以 `.github.com` 开头作为子域后缀，返回 false。
3. 相对路径仍由前导 `/` 且非 `//` 的检查覆盖，协议相对 URL 被拒绝。
4. 该修正完整覆盖攻击面：所有外部主机均无法通过精确白名单匹配。
