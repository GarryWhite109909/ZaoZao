```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Storage;
use App\Models\Post;
use App\Models\Tag;

class DbController extends Controller
{
    // routes/web.php: Route::post('/db/export', [DbController::class, 'exportContent']);
    public function exportContent(Request $request)
    {
        $filename = $request->input('filename');

        if ($filename) {
            // 直接用用户提供的文件名拼接磁盘路径，未做 basename/白名单校验
            $path = 'backups/' . $filename;

            if (!Storage::disk('local')->exists($path)) {
                abort(404);
            }

            return response()->download(
                Storage::disk('local')->path($path),
                basename($filename)
            );
        }

        return response()->streamDownload(function () {
            echo json_encode([
                'posts' => Post::all()->toArray(),
                'tags' => Tag::all()->toArray()
            ]);
        }, 'content-export-' . now()->format('YmdHis') . '.json');
    }
}
```

1. 第 15 行：`$request->input('filename')` 是外部输入入口（source），攻击者可传入任意字符串如 `../../.env`。
2. 第 19 行：直接将用户输入拼接到存储相对路径 `'backups/' . $filename`，没有调用 `basename()`、`realpath()` 或白名单校验。
3. 第 21 行：`Storage::exists($path)` 会跟随 `../` 解析到 backups 目录之外的文件，仅作为存在性检查而非防御。
4. 第 23-26 行：`response()->download(Storage::path($path))` 是 sink——将解析后的绝对路径交给下载响应，攻击者可读取服务器上任意可读文件（路径遍历）。
5. 整个链路中 Laravel 的 Storage 抽象本身不阻止 `..` 序列，且控制器层无任何中间件或输入过滤拦截该参数，防御完全缺失。
