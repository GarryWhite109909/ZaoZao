```python
from flask import Flask, request, jsonify

app = Flask(__name__)

# 全局翻译/配置字典，模拟 i18next 的 json 输出对象
TRANSLATIONS = {}

def deep_assign(target, key, value, separator='##'):
    # 与原版 gettext2json 相同：按分隔符切分 key，逐段动态写入嵌套 dict
    segments = key.split(separator)
    node = target
    for seg in segments[:-1]:
        if not isinstance(node.get(seg), dict):
            node[seg] = {}
        node = node[seg]
    node[segments[-1]] = value

@app.route('/import', methods=['POST'])
def import_translations():
    payload = request.get_json(force=True) or {}
    separator = payload.get('keyseparator') or '##'
    entries = payload.get('translations')
    if not isinstance(entries, list):
        return jsonify({'error': 'translations must be a list'}), 400

    for entry in entries:
        key = entry.get('key', '')
        value = entry.get('value', '')
        if len(key) == 0:
            continue
        # 无任何键名白名单/黑名单校验，直接进入 deep_assign
        deep_assign(TRANSLATIONS, key, value, separator)

    return jsonify({'ok': True})

@app.route('/config/<name>')
def get_config(name):
    return jsonify({name: TRANSLATIONS.get(name)})

if __name__ == '__main__':
    app.run()
```

1. 第 22 行 `request.get_json()` 是唯一外部输入入口，`payload['translations']` 中每条 `entry['key']` 与 `entry['value']` 完全由攻击者控制，第 33 行直接传入 `deep_assign`，可达性成立。
2. 第 6-14 行 `deep_assign` 按分隔符 `##` 切分后逐段 `node[seg] = {}` / `node[segments[-1]] = value` 动态写键；全程无任何对段名的白名单、正则或替换过滤（第 20-21 行仅取默认分隔符），防御缺失。
3. Python 类污染等价 sink：攻击者提交 key 为 `__class__##__init__##__globals__##SECRET`（或指向全局 `app.config`、其他模块属性）的条目，即可沿对象图写入任意可变属性——与 JS 原型污染语义结构完全一致：source（JSON 键）→ 动态键赋值 sink。
4. 第二入口确认：`get_config` 路由只读不写，无替代污染通道；但污染一旦发生即影响进程内所有共享该对象的代码路径，且 `/import` 本身就是唯一也是充分的写入口。
5. 结论：存在 CWE-1336 等价漏洞（Python class/global pollution），风险 High。
