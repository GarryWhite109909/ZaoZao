from flask import Flask, request, jsonify

app = Flask(__name__)

translations = {}

def deep_assign(container, path, value, separator='##'):
    keys = path.split(separator)
    node = container
    for k in keys[:-1]:
        if not hasattr(node, '__setitem__'):
            return
        if k not in node or not isinstance(node[k], dict):
            node[k] = {}
        node = node[k]
    node[keys[-1]] = value

@app.route('/api/convert', methods=['POST'])
def convert():
    payload = request.get_json(force=True)
    locale = payload.get('locale', 'en')
    entries = payload.get('entries', [])
    result = {}
    for entry in entries:
        key = entry.get('key', '')
        value = entry.get('value', '')
        if key == '':
            continue
        ctx = entry.get('context', '')
        target_key = f'{key}_{ctx}' if ctx else key
        deep_assign(result, target_key, value)
    translations[locale] = result
    return jsonify({'status': 'ok', 'count': len(result)})

if __name__ == '__main__':
    app.run()

2. 第 22 行将用户提供的 `key` 原样传入 `deep_assign`，与原代码中按 `##` 分隔符拆分嵌套键的逻辑等价。
3. 第 6~13 行的 `deep_assign` 是 sink：逐段把用户字符串作为字典键写入，未过滤 `__class__`、`__init__`、`__globals__` 等危险键名——Python 中污染对象属性可通过 `__class__.__init__.__globals__` 链触及全局命名空间，等价于 JS 的 prototype pollution（CWE-1336）。
4. 第 10 行仅检查 `isinstance(node[k], dict)`，但首次写入时直接创建普通 dict 并继续用用户键索引，防御形同虚设；且对已存在的非 dict 节点直接覆盖，可劫持已有结构。
5. 全链路（第 15 → 22 → 12 行）没有任何键名黑名单、路径规范化或不可变容器保护，source 到 sink 完全贯通。
