```code
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""数据运维顶层脚本：常量表驱动批量执行固定 SQL（每日归档清理）"""

import sqlite3

# 固定任务表：全部为编译期写死的字面量，无任何外部输入
TASKS = [
    ("archive_logs", "DELETE FROM access_logs WHERE created_at < date('now', '-90 day')"),
    ("purge_sessions", "DELETE FROM sessions WHERE expires_at < datetime('now')"),
    ("vacuum_hint", "PRAGMA optimize"),
]

DB_PATH = "/var/data/ops/maintenance.db"
LOG_FILE = "/var/log/ops/maintenance.log"


def run_task(conn, name, sql):
    # 参数均为调用点传入的常量元组元素
    conn.execute(sql)
    print("done:", name)


def main():
    conn = sqlite3.connect(DB_PATH)  # DB_PATH 为模块级常量字符串
    try:
        for task in TASKS:
            run_task(conn, *task)
        with open(LOG_FILE, "a") as f:  # LOG_FILE 为常量路径
            f.write("maintenance finished
")
    finally:
        conn.close()


if __name__ == "__main__":
    main()
```

1. 第 20 行 `conn.execute(sql)`：`sql` 来自第 10~14 行 `TASKS` 常量表中的字面量 SQL 字符串，经第 30 行循环以 `*task` 解包传入，全程无外部输入参与拼接。
2. 第 29 行 `sqlite3.connect(DB_PATH)`：`DB_PATH` 是第 17 行的模块级常量字符串 `/var/data/ops/maintenance.db`，非环境变量或命令行参数。
3. 第 33 行 `open(LOG_FILE, 'a')`：`LOG_FILE` 为第 18 行常量路径，写入内容为固定字符串，无污点数据流入文件系统。
4. 入口唯一性：脚本无 `argv`/`input`/`environ`/网络读取；`run_task` 仅在 `main` 内被固定常量调用，`if __name__ == '__main__'` 保证无导入侧执行通道，不存在第二入口或替代污点路径。
