## 几个我踩过的坑，帮你避开

1. "黑名单可绕过"这种话信息量为零——请把**具体绕过字符串**写出来（`....//`、`$()`、`%0a`、大小写变体），我才能真正理解防御为什么失败。
2. **代码里的注释经常在撒谎**（"这里安全"其实有洞、"这里有洞"其实防御有效），注释里自己标的行号也经常是错的——请只看代码真实行为和真实行位，忽略注释声称的一切。
3. 有些防御是**组合生效**的（A 单独不行 + B 单独不行 = AB 一起封死），请逐层拆开看，别只看单点。
4. 如果硬编码的密钥/token 可以伪造会话或签名，从而**绕过看似存在的认证门**，这就是一条组合链，请写出来。
5. 代码执行类的编号判别轴是**哪个解释器最终消费这个字符串**：shell 消费 → CWE-78（`execSync(shell:true)`、`["sh","-c",输入]` 都算，有无显式 shell 层不论）；`eval()`/`assert()`/`new Function()`/`preg_replace /e` 动态求值消费 → CWE-95/94 族（细分见判别笔记）；模板引擎把输入当代码渲染 → CWE-1336——三者别混。另外 `eval("var x = " + input)` 和 `eval(input)` 在我这里是同一类，别按"直接进 vs 拼接进"分成两种定性。
6. 如果你是**从部署/运维角度**认为"这不会被打到"，那属于我的业务决策范围——请只报告代码层面可达的攻击面，部署上的事我自己判断。
7. 如果某个判断**依赖我没贴出来的代码**（调用方、框架行为、运行环境、被截断的函数体），请显式标一句"样本外假设"——我要练习区分"代码内可证"和"凭经验猜测"。如果代码明显被截断了，直接告诉我要补哪段，别猜着补全分析。
8. 我经常一条消息连发几个案例：**每个案例的行号、变量名、结论请逐条独立核对**——我遇到过把上一个样本的行号和结论串写到下一个样本的情况。
9. 还有一类我容易漏的：**没有传统污点流的设计/配置缺陷**也请照实报告——弱协议/弱算法（TLS 1.0/SSL、MD5/SHA1——签名/MAC 用途和口令存储的快哈希都算）、不完整禁用列表/可绕过黑名单当防线、服务以 root 等过度权限运行（CWE-250）、可预测随机数生成令牌密钥（CWE-338）、禁用证书校验且无补偿控制（CWE-295）、硬编码凭证（CWE-798）——这些都给对应的 CWE。

## 样本类型说明

你看到的代码有三种来源：
- **单文件**：直接分析完整文件
- **差分对**：同一个文件的两个版本（版本A、版本B）。请**分别独立分析**，版本A 的分析中不要参考版本 B 的任何内容；也不要因为"两个版本不一样"就预设哪个有问题——每个版本只按它自己的代码判
- **文件切片**：大文件的一个片段，可能缺少上下文——不可达的方向请标注"样本外"

**特殊：带官方结论的复核包**（包头标 `| redistill`，包内有"官方结论（待你验证）"区块）。这类是我自己推不稳的案例：把官方结论当作**待验证假设**，从代码出发推出支持它的完整证据链（污点路径/防御链逐行号）；如果你的推导确实到不了那个结论，写 `disagree: <哪一步断了、代码事实是什么>`——推不出来直说是有价值的，**禁止为凑结论编造不存在的行号、变量或数据流**。其中结论为"安全"的复核包：`防御:` 栏必须逐段给出**行号 + 什么机制 + 为什么不可旁路**，一句"已有校验"不合格。

## 我的判别笔记（结论里的 CWE 编号请按这份对齐；笔记本身整理错了也请直接指出）

先问"注入的目标是什么"，再定编号：
- sink 是 OS 程序执行 → CWE-78（**有没有 shell 层都算**，`["sh","-c",输入]` 也是 78）；注入的是"非 OS 的命令语言"（sed 脚本、IMAP/SMTP、应用配置语言）→ CWE-77；命令名固定、输入只落参数位 → CWE-88——**前提是输入能注入参数结构**（前导 `-`/`--` 被当新选项，如 `ssh -oProxyCommand=`、`tar --checkpoint-action=exec=`，或固定命令对该参数二次解析）；argv 单元素完整传递、无选项语义、无二次解析 = 无漏洞，别硬凑 88
- 不可信数据进入 `eval()/exec()/Function()/preg_replace /e` 等**动态求值调用的求值位** → CWE-95——无论整段直传还是拼进代码文本（我查过 MITRE 4.20：95 是 94 的 Variant 子类，映射按更具体的 sink 优先，**拼接与否不影响 95 定位**；旧笔记"拼接主记 94"的统一口径已作废，统一主记 95，正文可注明旧口径差异）；拼出的代码**落盘后再执行**——写入 .py/.js/.sh 交解释器、存库后取出执行——正文注明 CWE-96；生成代码走**非求值器**的编译/执行路径（动态 import 之外的生成-编译链）或需父类兜底 → 94；输入进入**模板源码字符串位**被引擎渲染 → CWE-1336（`render(name=user)` 只是变量值，不算）；printf/format 的**格式串位**被控 → CWE-134；框架表达式求值器（SpEL/OGNL/EL）→ CWE-917；终端 ANSI/OSC 转义序列未净化 → CWE-150
- sink 是 SQL（含 ORM raw）→ CWE-89；非 SQL 的查询逻辑（MongoDB 操作符、HQL）→ CWE-943（HQL 也有记 89 的惯例，本笔记统一 943，主编号别摇摆）；XPath → CWE-643；LDAP 过滤器 → CWE-90
- 路径/文件名外部可控：出现 `../` 或等价目录上跳（含 `..\`、`%2e%2e%2f`、`..%c0%af`、symlink 逃逸）→ CWE-22；攻击者直接控绝对路径（如 `/etc/passwd`，无上跳）按本笔记也主记 22、正文可注明 CWE-73；仅文件名可控、目录不可控 → CWE-73
- 未净化输入进入浏览器执行上下文（HTML/属性/JS 字符串）→ CWE-79，按**最终渲染上下文**判，不看变量叫什么
- 不可信数据进反序列化器（readObject/pickle/unserialize）→ CWE-502（仅解析 JSON 等纯数据格式不算）。**受限反序列化器是有效防御**：`find_class`/resolve 白名单要同时满足（a）白名单内没有把输入当逻辑执行的构造器/方法、（b）可调用对象来源池封闭（REDUCE 链无法二段提升）才算防御有效。自写持久化通道（未验签的存储回读）算不算不可信输入看信任边界：攻击者取得该通道写入权的成本低于直接 RCE 成本 → 按 502 计，否则降为纵深防御缺失。XML 解析允许外部实体/DTD 且输入不可信 → CWE-611；把不可信流直接交给 JAXP 系列（`XPath.evaluate(InputSource,…)`、`Validator.validate(StreamSource)`、`Transformer.transform`）未设 `disallow-doctype-decl` 同样是 611，**`FEATURE_SECURE_PROCESSING` 不算有效防御**；纯实体膨胀 DoS（billion laughs、无外部实体）→ 正文注明 CWE-776，按 DoS 档定级
- 服务端取回 URL 内容且目的地未校验 → CWE-918；借产品的身份/网络位置发请求（回环信任），最贴形是产品作为**非预期代理**把外部请求转交内部高权限服务 → CWE-441；内部服务"只信 localhost 所以不鉴权"按缺失认证/授权记 CWE-306/862，不算 441；骗浏览器跳转 → CWE-601
- 没有授权检查 → CWE-862；查了但对象用户可控（IDOR）→ CWE-639；关键功能连认证都没有 → CWE-306；状态变更端点只靠自动携带的 Cookie、无 token/Origin 校验 → CWE-352。**SameSite 只有 Strict（或 Lax 且变更端点非 GET）才算一层防御**——Lax 在顶层导航 GET 上照带 Cookie；浏览器对未声明 SameSite 的 Cookie 默认按 Lax 处理，样本没写 SameSite 时别想当然按有防护算
- JWT `alg=none` / 签名验证被禁用 → CWE-347（不是 327：不是算法弱，是验证被关了）
- 用户可控动态键写入共享 dict/对象 → CWE-915（Python dict 没有原型链，禁止写"原型污染"叙事）；**JavaScript** 的 `obj[k]=v` 且 k 可为 `__proto__`/`constructor` → 正文注明 CWE-1321，同样不写"原型污染"字样敷衍、要写出完整链
- 整数溢出/回绕：不可信输入进长度/偏移/索引/数量位，参与 `a + b`/`a * b`/移位/位掩码运算或宽窄类型转换后用于**边界检查、分配、拷贝、寻址**，且检查本身可被溢出绕过 → CWE-190（经典形态：`off + len > b.length` 在 `off+len` 溢出为负时放行，正确写法是 `len > b.length - off`）；JS 的索引回绕/负值规整缺陷（`index += origin`、位掩码寻址）同判；溢出结果没流向边界检查/分配/寻址的纯算术回绕不报或降档
- 参数化/预编译/占位符查询 = SQL 注入的**有效防御，但只覆盖值位**；表名/列名/`ORDER BY` 字段/排序方向等标识符位不可绑定，回退拼接仍是 89——判"安全"前核对参数化覆盖了**所有**输入可达位；单点 replace/黑名单字符过滤 = **伪防御**（要核它漏了什么字符、作用位置对不对）
- 硬编码凭证字面量用于认证/加密/签名 → CWE-798（"定义了但没使用"也是 798，风险降档即可；正文可加注更精确编号：在用且用于加密/签名的密钥 → CWE-321，未使用的配置项 → CWE-547）

## 风险等级我目前这么定（觉得哪条不合理，说出你的定法和理由）

- Critical = 可达 RCE / 认证绕过 / 凭证直接泄露（认证门后就是 RCE 仍算 Critical）；"可达"要求**链上每一跳都在样本内可证**（路径、表名、组件行为全部代码内），任一跳依赖样本外（web root 可写、目标装有特定组件、上游权限）→ 记 High 并标"理论链"；凭证直接泄露限定为**可直接动用**的（私钥、数据库/服务账号口令、能伪造会话或签名的 secret），"像凭证但代码内无使用点"按 798 未使用降档
- High = 注入类 / SSRF / XSS / 越权读写；没有利用链演示的理论 RCE 也记 High；等级按**组合链最坏情形**判，但同样受上一条"样本内可证"约束；Critical 与 High 两可时记 High 并写明理由，不虚高
- Medium = 信息泄露 / 配置错误 / 有限 DoS / 定义未使用的硬编码凭证
- Low = 影响极小

// IsFile returns true if the object @ path is a file
func IsFile(path string) bool {
	info, err := os.Stat(path)
	if err != nil {
		return false
	}
	return info.Mode().IsRegular()
}

// IsDir returns true if the object @ path is a dir
func IsDir(path string) bool {
	info, err := os.Stat(path)
	if err != nil {
		return false
	}

	return info.IsDir()
}

// SanitizePath cleans and resolves the given file path to an absolute path.
// This prevents path traversal and ensures consistency in file handling.
func SanitizePath(path string) (string, error) {
	// Clean the input path to eliminate any redundant or unsafe elements.
	// Example: "/foo/../bar" becomes "/bar"
	cleanPath := filepath.Clean(path)

	// Convert to absolute path to avoid ambiguity and ensure safe file access.
	absPath, err := filepath.Abs(cleanPath)
	if err != nil {
		return "", errors.Wrap(err, "Failed to get absolute path")
	}

	return absPath, nil
}

// FileExists returns true if the file @ path exists
func FileExists(path string) bool {
	_, err := os.Stat(path)
	return err == nil
}

// EnsureDirExists checks if the directory exists, creates it if it doesn't
func EnsureDirExists(ctx context.Context, loggerInstance logger.Logger, dir string) error {
	if _, err := os.Stat(dir); os.IsNotExist(err) {
		loggerInstance.DebugWithCtx(ctx,
			"Creating directory as it does not exist",
			"directory", dir)

		// we need 755 permission to allow running nuclio function with non-root SecurityContext
		if err := os.MkdirAll(dir, 0755); err != nil {
			return err
		}
	}
	return nil
}

// StringSliceToIntSlice converts slices of strings to slices of int. e.g. ["1", "3"] -> [1, 3]
func StringSliceToIntSlice(stringSlice []string) ([]int, error) {
	var result []int

	for _, stringValue := range stringSlice {
		var intValue int
		var err error

		if intValue, err = strconv.Atoi(stringValue); err != nil {
			return nil, err
		}

		result = append(result, intValue)
	}

	return result, nil
}

// StringSliceContainsString returns whether the input str is in the slice
func StringSliceContainsString(slice []string, str string) bool {
	for _, stringInSlice := range slice {
		if stringInSlice == str {
			return true
		}
	}

	return false
}

// StringSliceContainsStringPrefix returns whether the input str has prefix
func StringSliceContainsStringPrefix(prefixes []string, str string) bool {
	for _, prefix := range prefixes {
		if strings.HasPrefix(str, prefix) {
			return true
		}
	}
	return false
}

// StringSliceContainsStringSuffix returns whether the input str has suffix

		}
	}
	return false
}

// StringSliceContainsStringCaseInsensitive returns whether the input str is in the slice case-insensitive

			return true
		}
	}

	return false
}

// RetryUntilSuccessfulOnErrorPatterns calls callback every interval for duration as long as error pattern is matched
// the callback argument retryCounter is the number of times the callback was called
func RetryUntilSuccessfulOnErrorPatterns(
	duration time.Duration,
	interval time.Duration,
	errorRegexPatterns []string,
	callback func(retryCounter int) (string, error)) error {

	return retryUntilSuccessful(duration, interval, func(retryCounter int) (bool, error) {
		callbackErrorStr, err := callback(retryCounter)

		if callbackErrorStr == "" {

			// no error message means no retry needed
			return false, err
		}

		// find a matching error pattern
		if !MatchStringPatterns(errorRegexPatterns, callbackErrorStr) {

			// no error pattern found, dont retry, bail
			return false, errors.Errorf("Failed matching an error pattern for callback: %s", callbackErrorStr)
		}

		return true, err

	})
}

// retryUntilSuccessful calls callback every interval until duration as long as it should retry
func retryUntilSuccessful(duration time.Duration,
	interval time.Duration,
	callback func(int) (bool, error)) error {
	var lastErr error
	timedOutErrorMessage := "Timed out waiting until successful"
	deadline := time.Now().Add(duration)

	// while we haven't passed the deadline
	var retryCounter int
	for !time.Now().After(deadline) {
		shouldRetry, err := callback(retryCounter)
		lastErr = err
		if !shouldRetry {
			return err
		}
		retryCounter++
		time.Sleep(interval)
		continue

	}
	if lastErr != nil {

		// wrap last error
		return errors.Wrapf(lastErr, "%s", timedOutErrorMessage)
	}

	// duration expired without any last error
	return errors.Errorf("%s", timedOutErrorMessage)
}

// RemoveEmptyLines removes all empty lines from a string
func RemoveEmptyLines(input string) string {
	var nonEmptyLines []string

	scanner := bufio.NewScanner(strings.NewReader(input))

	// iterate over input line by line. if the line is not empty, shove it to the list
	for scanner.Scan() {
		line := scanner.Text()

		if len(line) != 0 {
			nonEmptyLines = append(nonEmptyLines, line)
		}
	}

	// join the strings with a newline between them
	return strings.Join(nonEmptyLines, "\n")
}

// RemoveWindowsCarriage removes windows carriage character '\r' when it follows by '\n'
func RemoveWindowsCarriage(b []byte) []byte {
	n := utf8.RuneCount(b)
	for i := 0; i < n-1; i++ {
		if b[i] == '\r' && b[i+1] == '\n' {

			// remove \r, keep \n
			b = append(b[:i], b[i+1:]...)
			n--
		}
	}
	return b
}

func FixEscapeChars(s string) string {

		"\\n":  "\n",
		"\\t":  "\t",

	for oldChar, newChar := range escapeCharsMap {

	}

	return s
}

func GetSourceDir() string {

	// get caller filename
	_, fileName, _, _ := runtime.Caller(0)

	// get filename dir
	dirName := path.Dir(fileName)

	for {

		// we determine source dir by having a `go.mod` file there
		if _, err := os.Stat(filepath.Join(dirName, "go.mod")); !os.IsNotExist(err) {
			return dirName
		}

		// if we didn't find source yet, try on parent dir
		dirName = filepath.Dir(dirName)

		// we're out of parents, stop here
		if dirName == "/" {
			return dirName
		}
	}
}

// LabelsMapMatchByLabelSelector returns whether a labelsMap is matched by an encoded label selector
// corresponding to https://kubernetes.io/docs/concepts/overview/working-with-objects/labels/
//
// Example:
//
//	labelsMap:
//	  a: b
//	  c: d
//	encodedLabelSelector: a=b
//
// returns true
func LabelsMapMatchByLabelSelector(labelSelector string, labelsMap map[string]string) (bool, error) {

	parsedLabelSelector, err := metav1.ParseToLabelSelector(labelSelector)
	if err != nil {
		return false, errors.Wrap(err, "Failed to parse label selector")
	}
	selector, err := metav1.LabelSelectorAsSelector(parsedLabelSelector)
	if err != nil {
		return false, errors.Wrap(err, "Failed to get selector from label selector")
	}
	return selector.Matches(labels.Set(labelsMap)), nil
}

// SanitizeResponseData tries to parse byte data as html. if it succeeds, it is returned sanitized,
// otherwise the original data is returned.
// func SanitizeResponseData(data []byte) []byte {
func SanitizeResponseData(data []byte, headers http.Header) []byte {
	// check if the content type contains html or javascript
	contentType := headers.Get("Content-Type")
	if contentType == "" || (!strings.Contains(contentType, "html") && !strings.Contains(contentType, "javascript")) {
		return data
	}

	// attempt to parse the input data as HTML
	_, err := html.Parse(bytes.NewReader(data))
	if err != nil {
		// if there is an error in parsing, it's not HTML, return data as is
		return data
	}

	// the data is HTML, sanitize it
	policy := bluemonday.UGCPolicy()
	sanitizedData := policy.Sanitize(string(data))
	return []byte(sanitizedData)
}

// IsPathWithinDir reports whether targetPath resolves to a location strictly inside dir.
// Both arguments are resolved to absolute paths first, so the check is robust against
// "../" traversal sequences in targetPath. A path equal to dir is not considered within it.
// Use this to prevent path traversal (CWE-22) before writing to a user-influenced path.
func IsPathWithinDir(targetPath, dir string) (bool, error) {
	absTargetPath, err := filepath.Abs(targetPath)
	if err != nil {
		return false, errors.Wrap(err, "Failed to resolve target path")
	}
	absDir, err := filepath.Abs(dir)
	if err != nil {
		return false, errors.Wrap(err, "Failed to resolve dir")
	}

	relPath, err := filepath.Rel(absDir, absTargetPath)
	if err != nil {
		// the paths share no common base (e.g. different Windows volumes) - not within
		return false, nil
	}

	return relPath != "." &&
		relPath != ".." &&
		!strings.HasPrefix(relPath, ".."+string(os.PathSeparator)), nil
}

// RemoveEmptyLines removes all empty lines from a string
func RemoveEmptyLines(input string) string {
	var nonEmptyLines []string

	scanner := bufio.NewScanner(strings.NewReader(input))

	// iterate over input line by line. if the line is not empty, shove it to the list
	for scanner.Scan() {
		line := scanner.Text()

		if len(line) != 0 {
			nonEmptyLines = append(nonEmptyLines, line)
		}
	}

	// join the strings with a newline between them
	return strings.Join(nonEmptyLines, "\n")
}

// RemoveWindowsCarriage removes windows carriage character '\r' when it follows by '\n'
func RemoveWindowsCarriage(b []byte) []byte {
	n := utf8.RuneCount(b)
	for i := 0; i < n-1; i++ {
		if b[i] == '\r' && b[i+1] == '\n' {

			// remove \r, keep \n
			b = append(b[:i], b[i+1:]...)
			n--
		}
	}
	return b
}

func FixEscapeChars(s string) string {
	escapeCharsMap := map[string]string{
		"\\n":  "\n",
		"\\t":  "\t",
		"\\\\": "\\",
		"\\\"": "\"",
	}

	for oldChar, newChar := range escapeCharsMap {
		s = strings.ReplaceAll(s, oldChar, newChar)
	}

	return s
}

func GetSourceDir() string {

	// get caller filename
	_, fileName, _, _ := runtime.Caller(0)

	// get filename dir
	dirName := path.Dir(fileName)

	for {

		// we determine source dir by having a `go.mod` file there
		if _, err := os.Stat(filepath.Join(dirName, "go.mod")); !os.IsNotExist(err) {
			return dirName
		}

		// if we didn't find source yet, try on parent dir
		dirName = filepath.Dir(dirName)

		// we're out of parents, stop here
		if dirName == "/" {
			return dirName
		}
	}
}

// LabelsMapMatchByLabelSelector returns whether a labelsMap is matched by an encoded label selector
// corresponding to https://kubernetes.io/docs/concepts/overview/working-with-objects/labels/
//
// Example:
//
//	labelsMap:
//	  a: b
//	  c: d
//	encodedLabelSelector: a=b
//
// returns true
func LabelsMapMatchByLabelSelector(labelSelector string, labelsMap map[string]string) (bool, error) {

	parsedLabelSelector, err := metav1.ParseToLabelSelector(labelSelector)
	if err != nil {
		return false, errors.Wrap(err, "Failed to parse label selector")
	}
	selector, err := metav1.LabelSelectorAsSelector(parsedLabelSelector)
	if err != nil {
		return false, errors.Wrap(err, "Failed to get selector from label selector")
	}
	return selector.Matches(labels.Set(labelsMap)), nil
}

}

// PopulateFieldsFromValues populates empty fields with values if the value is not zero.
// the fieldsToValues argument is a map of pointers to fields to populate and values.
func PopulateFieldsFromValues[T string | bool | int](fieldsToValues map[*T]T) {
	var zeroValue T
	for field, value := range fieldsToValues {

			*field = value
		}
	}
}

// SanitizeResponseData tries to parse byte data as html. if it succeeds, it is returned sanitized,
// otherwise the original data is returned.
// func SanitizeResponseData(data []byte) []byte {
func SanitizeResponseData(data []byte, headers http.Header) []byte {
	// check if the content type contains html or javascript
	contentType := headers.Get("Content-Type")
	if contentType == "" || (!strings.Contains(contentType, "html") && !strings.Contains(contentType, "javascript")) {
		return data
	}

	// attempt to parse the input data as HTML
	_, err := html.Parse(bytes.NewReader(data))
	if err != nil {
		// if there is an error in parsing, it's not HTML, return data as is
		return data
	}

	// the data is HTML, sanitize it
	policy := bluemonday.UGCPolicy()
	sanitizedData := policy.Sanitize(string(data))
	return []byte(sanitizedData)
}

// ImageHasRegistry returns true if the image string includes an explicit registry domain.
// A registry is assumed present if the first component contains a '.' or ':' (e.g., "registry.io/image").
func ImageHasRegistry(image string) bool {
	image = strings.TrimSpace(image)
	slashIndex := strings.Index(image, "/")
	if slashIndex == -1 {
		return false
	}
	firstSegment := image[:slashIndex]
	return strings.Contains(firstSegment, ".") || strings.Contains(firstSegment, ":")
}
