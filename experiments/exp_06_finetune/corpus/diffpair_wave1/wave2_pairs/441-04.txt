# wave2 pair 441-04 | CWE-290 | PHP | 成对同码
# oracle_vuln（污点路径，行号自版本A围栏后起算）：
  - L5 `HTTP_X_FORWARDED_HOST` source：转发主机头由客户端注入
  - L5 `=== 'ops\.corp\.internal'` sink：内部域声明命中即放行 internal 路径
# anchor_vuln: 非 441 因为无转发语义；内部来源域由转发头自报决定=身份欺骗，按 CWE-290 定位——预审教师轴 20260913 定版。『是否来自内部运维域』由 X-Forwarded-Host 自报决定，属于借转发头冒充网络位置的信任错置（441）。
# oracle_safe（防御链）：
  - L5 `REMOTE_ADDR` 防御：对端地址判定内部来源
  - L5 `TRUSTED_PROXY_NET` 受信代理网段白名单
  - L6 `HTTP_X_FORWARDED_HOST.*展示` 转发头仅展示用途（注释锚定）
# anchor_safe: 防御为何不可旁路：内部来源改由 REMOTE_ADDR 对受信代理网段的判定决定；X-Forwarded-Host 仅作展示信息，头值无法再影响放行分支。

#### 版本A（vuln，18 行）
```php
<?php
// routes/protection.php
function guard(string $path): void {
    if (str_starts_with($path, '/internal/')) {
        $trusted = ($_SERVER['HTTP_X_FORWARDED_HOST'] ?? '') === 'ops.corp.internal';
        if (!$trusted) {
            http_response_code(403);
            exit('forbidden');
        }
    }
    if (str_starts_with($path, '/admin') && empty($_COOKIE['session'])) {
        http_response_code(401);
        exit('unauthorized');
    }
}
$path = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
guard($path);
echo "ok";
```
#### 版本B（safe，19 行）
```php
<?php
// routes/protection.php
function guard(string $path): void {
    if (str_starts_with($path, '/internal/')) {
        $isInternal = filter_var($_SERVER['REMOTE_ADDR'], FILTER_VALIDATE_IP, FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE) === false; // TRUSTED_PROXY_NET 网段判定
        $trusted = $isInternal; // HTTP_X_FORWARDED_HOST 仅作展示信息
        if (!$trusted) {
            http_response_code(403);
            exit('forbidden');
        }
    }
    if (str_starts_with($path, '/admin') && empty($_COOKIE['session'])) {
        http_response_code(401);
        exit('unauthorized');
    }
}
$path = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
guard($path);
echo "ok";
```
