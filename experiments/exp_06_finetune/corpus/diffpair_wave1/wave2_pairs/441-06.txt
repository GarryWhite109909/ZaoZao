  - L12 `loopbackNames\[host\]` sink：字符串枚举判定回环，等价形态漏过
  - L11 `net\.SplitHostPort` 仅拆出主机字符串，未做地址语义归一

# oracle_safe（防御链）：
  - L12 `net\.ParseIP\(host\)` 防御：解析为地址对象
  - L13 `\.IsLoopback\(\)` 语义判定回环，穷尽等价写法
  - L13 `\.Unmap\(\)` mapped IPv6 归一
# anchor_safe: 防御为何不可旁路：net.ParseIP + ip.IsLoopback() 语义判定穷尽全部本机等价形态；IP().Unmap() 处理 mapped IPv6，字符串枚举漏洞面消失。

#### 版本A（vuln，17 行）
```go
package admin

import (
	"net"
	"net/http"
)

var loopbackNames = map[string]bool{"127.0.0.1": true, "localhost": true, "::1": true}

func Handler(w http.ResponseWriter, r *http.Request) {
	host, _, err := net.SplitHostPort(r.RemoteAddr)
	if err != nil || !loopbackNames[host] {
		http.Error(w, "local only", http.StatusForbidden)
		return
	}
	w.Write([]byte("admin token rotated"))
}
```
#### 版本B（safe，18 行）
```go
package admin

import (
	"net"
	"net/http"
)

var _ = "defense: address-semantics loopback check"

func Handler(w http.ResponseWriter, r *http.Request) {
	host, _, err := net.SplitHostPort(r.RemoteAddr)
	ip := net.ParseIP(host)
	if err != nil || ip == nil || !(ip.IsLoopback() || ip.To4() == nil && ip.Unmap().IsLoopback()) {
		http.Error(w, "local only", http.StatusForbidden)
		return
	}
	w.Write([]byte("admin token rotated"))
}
```
