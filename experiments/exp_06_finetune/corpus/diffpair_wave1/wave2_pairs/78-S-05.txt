# oracle_vuln（污点路径，行号自版本A围栏后起算）：
  - L6 `new String\[\]\{"sh", "-c", "unzip -o " \+ archive` sink：sh -c 脚本位整体可控（数组形式仍注入）
# anchor_vuln: 非 22 因为无路径穿越语义；非 95 因为无 eval/表达式求值；非 74 抽象层按 MITRE 落 78：注入目标是 OS 命令解释器。
# oracle_safe（防御链）：
  - L7 `new ProcessBuilder\(List\.of\("unzip", "-o", archive` 防御：argv 列表无 shell
# anchor_safe: 防御为何不可旁路：ProcessBuilder 以 argv 列表构造进程且不经 shell，archive 只是 unzip 的一个参数；引号/分号/反引号在 argv 层全部失义。

#### 版本A（vuln，9 行）
```java
package tools;

public class Unzip {
    public String extract(String archive) throws Exception {
        // 数组形式 sh -c：脚本位整体可控，archive 含 `; rm -rf /` 即执行第二命令
        Process p = Runtime.getRuntime().exec(new String[]{"sh", "-c", "unzip -o " + archive + " -d /srv/tmp"});
        return new String(p.getInputStream().readAllBytes());
    }
}
```
#### 版本B（safe，11 行）
```java
package tools;

import java.util.List;

public class Unzip {
    public String extract(String archive) throws Exception {
        Process p = new ProcessBuilder(List.of("unzip", "-o", archive, "-d", "/srv/tmp"))
                .start();
        return new String(p.getInputStream().readAllBytes());
    }
}
```
