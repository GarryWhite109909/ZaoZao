# wave2 pair 95-10 | CWE-95 | PHP | 成对同码
# oracle_vuln（污点路径，行号自版本A围栏后起算）：
  - L5 `/e'` sink：/e 修饰符使替换串被 eval
  - L5 `strtoupper\("\$1"\)` 捕获组（用户数据）进入求值代码文本
# anchor_vuln: 非 94 因为被求值代码由 /e 修饰符的求值语义整体触发、用户数据经捕获组进入求值位，是 eval 族的动态求值残留（规格 95-06 归 95）；非 78 因为目标是 PHP 求值器；PHP 7 已移除 /e，此形态仅存于遗留代码面。
# oracle_safe（防御链）：
  - L4 `preg_replace_callback` 防御：回调替代 /e 求值
  - L6 `strtoupper\(\$m\[1\]\)` 捕获组仅作为数据传参
# anchor_safe: 防御为何不可旁路：preg_replace_callback 只把捕获组作为**数据**传给固定函数，替换逻辑是编译期确定的回调，不存在字符串被求值的路径。

### id=wave2-95-10 lang=php cve=N/A
#### 版本A（vuln，8 行）
```php
<?php
// lib/bbcode.php（PHP 5.x 遗留）
function render_bbcode($text) {
    // /e 修饰符：替换串作为 PHP 代码求值，捕获组 $1 来自用户文本
    return preg_replace('/\[b\](.*?)\[\/b\]/e', 'strtoupper("$1")', $text);
}

echo htmlspecialchars(render_bbcode($_POST['body']), ENT_QUOTES, 'UTF-8');
```
#### 版本B（safe，11 行）
```php
<?php
// lib/bbcode.php
function render_bbcode($text) {
    return preg_replace_callback(
        '/\[b\](.*?)\[\/b\]/',
        function ($m) { return strtoupper($m[1]); },
        $text
    );
}

echo htmlspecialchars(render_bbcode($_POST['body']), ENT_QUOTES, 'UTF-8');
```
