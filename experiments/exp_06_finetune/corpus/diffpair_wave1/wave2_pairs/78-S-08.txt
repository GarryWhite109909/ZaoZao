# wave2 pair 78-S-08 | CWE-78 | PHP | 成对同码
# oracle_vuln（污点路径，行号自版本A围栏后起算）：
  - L3 `\$_GET\['host'\]` source：请求参数
  - L4 `shell_exec\("ping -c 1 " \. \$host\)` sink：拼接进 shell 串
# anchor_vuln: 非 22 因为无路径穿越语义；非 95 因为无 eval/表达式求值；非 74 抽象层按 MITRE 落 78：注入目标是 OS 命令解释器。
# oracle_safe（防御链）：
  - L4 `escapeshellarg\(\$host\)` 防御：参数级转义，元字符字面化
# anchor_safe: 防御为何不可旁路：escapeshellarg 把 host 包成单引号字面量并转义内部引号（参数级转义），注入文本只能作为 ping 的单个 argv 参数存在——注意与 escapeshellcmd（命令级，防多命令分隔）的区别，此处需要的是参数级语义。

### id=wave2-78-S-08 lang=php cve=N/A
#### 版本A（vuln，6 行）
```php
<?php
// api/ping.php
$host = $_GET['host'] ?? '127.0.0.1';
$out = shell_exec("ping -c 1 " . $host);
header('Content-Type: text/plain');
echo $out;
```
#### 版本B（safe，6 行）
```php
<?php
// api/ping.php
$host = $_GET['host'] ?? '127.0.0.1';
$out = shell_exec("ping -c 1 " . escapeshellarg($host));
header('Content-Type: text/plain');
echo $out;
```
