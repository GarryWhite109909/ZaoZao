# oracle_vuln（污点路径，行号自版本A围栏后起算）：
  - L6 `req\.query\.domain` source：请求参数
  - L7 `exec\(`whois \$\{domain\}`` sink：模板串进默认 shell
# anchor_vuln: 非 22 因为无路径穿越语义；非 95 因为无 eval/表达式求值；非 74 抽象层按 MITRE 落 78：注入目标是 OS 命令解释器。
# oracle_safe（防御链）：
  - L7 `execFile\("whois", \[domain\]` 防御：execFile 默认无 shell，argv 独立
# anchor_safe: 防御为何不可旁路：execFile 默认不走 shell，domain 作为独立 argv 元素传给 whois，`$(...)`/反引号/管道符只是字面字符。

#### 版本A（vuln，13 行）
```javascript
const express = require("express");
const { exec } = require("child_process");
const app = express();

app.get("/whois", (req, res) => {
  const domain = req.query.domain || "example.com";
  exec(`whois ${domain}`, { timeout: 5000 }, (err, stdout) => {
    if (err) return res.status(400).json({ error: "failed" });
    res.type("text").send(stdout);
  });
});

app.listen(8080);
```
#### 版本B（safe，13 行）
```javascript
const express = require("express");
const { execFile } = require("child_process");
const app = express();

app.get("/whois", (req, res) => {
  const domain = req.query.domain || "example.com";
  execFile("whois", [domain], { timeout: 5000 }, (err, stdout) => {
    if (err) return res.status(400).json({ error: "failed" });
    res.type("text").send(stdout);
  });
});

app.listen(8080);
```
