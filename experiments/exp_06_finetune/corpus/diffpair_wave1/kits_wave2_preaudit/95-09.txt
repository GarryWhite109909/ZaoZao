#### 版本B（16 行）
```php
<?php
// prefs/import.php
$ALLOWED_PREFS = ['theme', 'pagesize', 'lang'];

$prefs = [];
foreach ($_POST as $key => $value) {
    if (!in_array($key, $ALLOWED_PREFS, true)) {
        continue;
    }
    $prefs[$key] = $value;
}
if (($_SESSION['is_admin'] ?? false) === true) {
    grant_admin();
}
save_prefs($prefs);
echo "imported";
```
